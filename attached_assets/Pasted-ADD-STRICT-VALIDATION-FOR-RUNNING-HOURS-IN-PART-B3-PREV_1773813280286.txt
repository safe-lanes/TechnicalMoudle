ADD STRICT VALIDATION FOR RUNNING HOURS IN PART B3 - PREVENT RH VALUES EXCEEDING COMPONENT ACTUAL RH
CRITICAL PROBLEM IDENTIFIED
There is a severe data integrity issue in the Work Order Form Part B - Section B3 (Running Hours) that is corrupting the entire maintenance cycle tracking system.

Problem Evidence:

Component: FO PURIFIER, NO.2 (702.005.02) - Vessel 11
Component's Actual RH in Running Hours Module: 870 hours
Current Reading entered in Work Order: 890 hours

Issue: The system allowed a user to enter 890 hours as the Current Reading when the component has only actually run 870 hours in total.

This is IMPOSSIBLE and creates the following problems:

❌ Data corruption: Work order shows maintenance done at 890 RH when component was only at 870 RH

❌ Broken cycle tracking: Next due RH calculated as 890 + 250 = 1,140 RH (incorrect)

❌ False history: Work history shows job done at a running hour that never happened

❌ Cascade failures: All future work orders for this component will have wrong due dates

❌ Loss of trust: System data becomes unreliable and cannot be used for compliance

Root Cause: The validation in Part B3 is NOT checking if the entered Current Reading exceeds the component's actual running hours from the Running Hours module.

REQUIRED VALIDATION LOGIC
VALIDATION RULE:
When a user enters a value in the "Current Reading" field in Part B3 - Running Hours section:

The entered value MUST NOT be greater than the component's actual current running hours as recorded in the Running Hours module.

Formula:

text
IF (Entered Current Reading > Component Actual RH from Running Hours Module)
THEN
    BLOCK SAVE
    SHOW ERROR
ELSE
    ALLOW SAVE

A. Real-Time Validation on Current Reading Field
Location: Work Order Form - Part B - Section B3 - "Current Reading" input field

When to Trigger Validation:

When user types in the Current Reading field (on blur/change event)

Before saving the work order (on Save button click)

Before submitting for approval

Validation Steps:

Fetch Component Actual RH:

Get the component ID from the current work order

Query the Running Hours module/database for this component's current RH

This should be the same value shown in the "Component Actual RH" column (which currently shows "Fetching...")

Get Entered Value:

Read the value entered by the user in "Current Reading" field

Convert to number and remove any formatting (commas, etc.)

Perform Comparison:

If Entered Current Reading > Component Actual RH:

Block the save operation

Do NOT allow form submission

If Entered Current Reading ≤ Component Actual RH:
