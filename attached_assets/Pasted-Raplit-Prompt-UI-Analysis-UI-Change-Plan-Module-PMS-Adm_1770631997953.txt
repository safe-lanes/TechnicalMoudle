Raplit Prompt — UI Analysis & UI Change Plan

Module: PMS → Admin → Fleet Data → Fleet Spares Information
Scope: Fleet Spares Information UI
Change Type: UI Change Only
UI Change Name: Alpha
Applicable Screen: Attached screenshot location only

Context

The Fleet Spares Information UI must follow the same layout, structure, and interaction pattern as the Fleet Jobs Information UI.

Currently:

Fleet Spares Information screen UI differs from Fleet Jobs Information

There is no selection mechanism for spares

Display columns are not aligned with expected Fleet Spares summary view

This prompt focuses only on UI structure and layout alignment.

Analysis Objectives

Analyse how Fleet Jobs Information UI is structured:

Table layout

Header positioning

Action/selection column

Row-level interaction pattern

Analyse the current Fleet Spares Information UI:

Missing selection column

Inconsistent column layout

UI mismatch with Fleet Jobs Information screen

Identify UI-level gaps only (no logic, no data source, no API analysis).

Required UI Changes
1. UI Layout Consistency

Fleet Spares Information UI must be visually and structurally identical to:
Fleet Jobs Information UI

No Excel-like table format to be applied unless already present in Fleet Jobs UI

2. Selection Column

Add one “Select” column as the first column

Each row must have a checkbox to select spares

Checkbox behavior must mirror Fleet Jobs Information UI selection behavior

No functional logic to be implemented in this prompt

3. Display Column Headers

The following column headers must be shown in the display table:

Select (Checkbox)

Part Code

Part Name

Part Number

Unit

Maker

Drawing Number

Position Number

Critical

Header naming must exactly match the above list.

UI Behavior Rules

Table headers must remain static

Rows must be displayed in read-only mode

No inline editing required

No sorting, filtering, or export logic to be added

No backend interaction changes

Constraints (Strict)

UI CHANGE ONLY

NO functionality or business logic changes

NO API or backend changes

NO schema or data source changes

NO validation logic

Apply changes only to the attached screenshot location

Do not impact Fleet Jobs, Fleet Components, or other screens

Alpha UI Change applicable only to this screen
