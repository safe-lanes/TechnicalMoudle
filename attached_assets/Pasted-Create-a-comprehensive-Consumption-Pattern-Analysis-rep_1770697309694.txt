Create a comprehensive "Consumption Pattern Analysis" report for the Stores module of the Planned Maintenance Software. This report should provide detailed insights into spare parts, lubricants, and chemicals consumption patterns.

Required Analysis & Metrics:

Consumption Trends Over Time:

Query the stores history/transaction tables to extract all "CONSUME" events

Analyze consumption by time period (monthly, quarterly, yearly)

Generate time-series charts showing consumption trends for each category (Stores, Lubes, Chemicals)

Item-wise Consumption Analysis:

Group consumption data by Item Code and Item Name

Calculate total quantity consumed per item over selectable date ranges

Identify top 10 most consumed items across all categories

Calculate consumption rate (qty consumed per month/quarter)

Category-wise Analysis:

Aggregate consumption by Stores Category (Mechanical, Safety, Consumables, etc.)

Compare consumption patterns between different categories

Show percentage distribution of consumption across categories

Stock Efficiency Metrics:

Calculate stock turnover ratio (consumption vs. average ROB)

Identify slow-moving items (low consumption relative to stock held)

Identify fast-moving items (high consumption rate)

Flag items approaching minimum stock levels based on consumption patterns

Equipment/Component Linkage:

Link consumption to specific components/equipment using Work Order data (Section B4: Spare Parts Consumed)

Identify which equipment/components consume the most spares

Analyze consumption patterns by equipment category

Forecasting Insights:

Calculate average monthly/quarterly consumption rates

Project future consumption based on historical patterns

Estimate reorder requirements based on consumption trends and minimum stock levels

Database Tables/Collections to Query:

Stores/Inventory table: For item details (item_code, item_name, category, uom, rob, min_stock, location)

Lubes table: For lubricant items

Chemicals table: For chemical items

History/Transactions table: For all consumption events (date, event_type, item_code, qty_change, rob_after, user, remarks)

Work Orders table: For linking consumption to maintenance activities

Spare Parts Consumed (Work Order Section B4): For detailed consumption per work order

Components table: For equipment hierarchy and linkage

Report Output Format:

Summary Dashboard: Key metrics (total items consumed, top consumers, consumption trends)

Detailed Tables: Item-wise consumption with filters by date range, category, vessel

Visualizations:

Time-series line charts for consumption trends

Bar charts for top consumed items

Pie charts for category distribution

Heat maps showing consumption patterns over time

Export Options: PDF, Excel formats with tabular data and charts

Date Range Filters: Selectable date ranges for custom analysis

Vessel Filter: Filter by specific vessels if multi-vessel data exists

Special Considerations:

Handle different UOM (pcs, ltr, kg, etc.) appropriately in calculations

Distinguish between consumption types: routine consumption vs. work order consumption

Account for negative qty_change (consumption) vs. positive (receiving/adjustment)

Provide drill-down capability from summary to detailed transaction history

Include user attribution to track who recorded consumption events

Generate the report generation logic, database queries, data processing functions, and PDF/Excel export functionality. Ensure the report integrates seamlessly with the existing PMS Reports section interface.
