| Rule                               | Description                                                                                                                                                                      |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| No future dates anywhere in Part B | All date fields must be ≤ today's date (05-03-2026).                                                                                                                             |
| No null submissions                | All mandatory fields (marked *) must be non-null before the Save button is actionable or before the record hits the database.                                                    |
| Duplicate Work Order prevention    | The Work Order number (WO-1772430876492-vqzjiol5f) must be unique in the DB. Saving the same WO twice should be blocked.                                                         |
| Partial save / draft state         | If a user saves partially (e.g., fills B2 but not B3), the system should either save as a "Draft" status (not "Completed") or prompt the user that mandatory fields are missing. |
| Immutability after approval        | Once the Chief Engineer approves, all Part B fields should become read-only/disabled — no further edits should be permitted without a formal amendment workflow.                 |
| Audit trail                        | Every save/edit action should record a timestamp and the user who made the change — this is a DB-level requirement for traceability.                                             |
| Character limits                   | Text areas like "Work Carried Out" and "Job Experience/Notes" should have a maximum character limit enforced at DB level (e.g., VARCHAR(2000)) to prevent overflow.              |
| Numeric field precision            | Running hours and manhours should be stored as DECIMAL(10,2) — not integer — to allow for fractional hours.                                                                      |
