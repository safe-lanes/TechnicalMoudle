TASK: ADD MAPPED / NOT MAPPED COUNT – JOBS & SPARES MAPPING (VESSEL SIDE)

Objective:

Enhance the **Jobs Mapping** and **Spares Mapping** sections to display **Mapped and Not Mapped counts on the Vessel side**, similar to the **Component Mapping section**.

--------------------------------------------------

1. Current Behavior

• Component Mapping section:
  - Shows Mapped and Not Mapped counts for Vessel side  

• Jobs Mapping and Spares Mapping:
  - Counts are NOT displayed  

--------------------------------------------------

2. Required Enhancement

• Add **Mapped and Not Mapped count display** in:

  - Jobs Mapping → Vessel side  
  - Spares Mapping → Vessel side  

--------------------------------------------------

3. Count Definitions

A. Mapped Count

• Number of records (Jobs / Spares)  
• Which are successfully mapped to Fleet  

--------------------------------------------------

B. Not Mapped Count

• Number of records (Jobs / Spares)  
• Which are NOT mapped to Fleet  

--------------------------------------------------

4. Data Scope

• Counts should be calculated based on:

  - Selected vessel  
  - Active records (if applicable)  

--------------------------------------------------

5. Logic Consistency

• Ensure the same logic used in **Component Mapping section** is applied:

  - Same filtering rules  
  - Same mapping definition  
  - Same data source approach  

--------------------------------------------------

6. UI Requirement

Display at top of Vessel side:

Example:

Mapped: 250  
Not Mapped: 75  

--------------------------------------------------

7. Validation

• Ensure counts match actual mapping data  
• No duplicate counting  
• Real-time update after mapping/unmapping actions  

--------------------------------------------------

Expected Result:

• Jobs Mapping and Spares Mapping sections display mapped and not mapped counts  
• Counts are accurate and consistent with Component Mapping logic  
• Improved visibility of mapping status on Vessel side
