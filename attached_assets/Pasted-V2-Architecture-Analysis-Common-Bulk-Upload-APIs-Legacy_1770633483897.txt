Analyze the existing bulk upload APIs and produce a clear architectural plan to support them under the V2 modular architecture, while keeping them common and reusable for all bulk upload flows.

🔒 Legacy Preservation Rule (NON-NEGOTIABLE)

All legacy bulk APIs must remain exactly as they are.

No changes to:

Routes

Logic

Schemas

Data

Legacy bulk flows must continue to work independently

V2 bulk architecture must be added in parallel, not as a replacement

Bulk upload APIs are common infrastructure, not module-specific logic.

V2 must support these APIs without duplication per module

Behavior, validations, and responses must remain identical to legacy

V2 must not import or call legacy bulk logic

V2 must reproduce logic, not reuse it
