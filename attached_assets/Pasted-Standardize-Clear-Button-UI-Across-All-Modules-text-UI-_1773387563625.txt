STYLING SPECIFICATIONS:

TEXT:
- Content: "Clear"
- Font family: Same as other UI elements (system font)
- Font size: Same as other filter elements
- Font weight: Regular (400) or Medium (500), NOT bold
- Letter spacing: Normal
- Text transform: None (keep as "Clear", not "CLEAR")

COLORS:
- Text color: Muted gray (e.g., #6B7280, #64748B, or similar gray from design system)
- NOT primary color (blue)
- NOT accent color (green/red)
- NOT black (#000)
- Hover text color: Slightly darker gray (e.g., #374151, #475569)

BACKGROUND:
- Default: Transparent OR very subtle gray background
- Hover: Light gray background (e.g., #F3F4F6, #F1F5F9)
- Active/Click: Slightly darker than hover state
- NO colored backgrounds (no blue, green, red)

BORDER:
- Option A: No border (borderless button)
- Option B: Subtle 1px gray border matching the design system
- Border radius: Small (2-4px) or medium (6-8px) to match other buttons

SPACING:
- Padding: 8-12px horizontal, 6-10px vertical (comfortable click target)
- Margin: 8-12px left margin to separate from previous filter element
- Minimum width: Auto (fits text width)
- Height: Match other filter elements (typically 36-40px)

CURSOR & INTERACTION:
- Cursor: pointer (hand cursor on hover)
- Transition: Smooth 150-200ms transition for color/background changes
- Focus state: Outline for keyboard navigation accessibility
- Disabled state: Grayed out if no filters are active (optional)
