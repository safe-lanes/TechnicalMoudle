Job Import Validations
1. Duplicate Validation
•	Combination of Job Code + Component Code + Vessel Code must be unique.
•	If duplicate records exist:
o	The first occurrence should be imported successfully.
o	The second and subsequent duplicate records should be rejected.
o	The rejected record should be displayed in the Import Summary with the error:
"Duplicate Job Code and Component Code combination."
________________________________________
2. WO Title
•	WO Title is mandatory.
•	If the WO Title is blank, the record should be skipped and not imported.
•	Error Message:
"WO Title is mandatory."
________________________________________
3. Component Code
•	Component Code is mandatory.
•	Blank values should not be imported.
•	The entered Component Code must exist in the selected vessel's Component List.
•	Error Messages:
o	"Component Code is mandatory."
o	"Component Code does not exist for the selected vessel."
________________________________________
4. Component Name
•	If a Component Name is provided in the import file, it should be ignored.
•	The system should automatically populate the Component Name based on the Component Code from the Component table.
________________________________________
5. Maintenance Basis
Allowed values:
•	Calendar
•	Running Hours
•	Dual Frequency
Any other value should be rejected.
Error Message:
"Invalid Maintenance Basis."
________________________________________
6. Interval Value
•	Only numeric values are allowed.
Error Message:
"Interval Value must be numeric."
________________________________________
7. Assigned To
The value must match one of the valid ranks configured in the system:
•	Master
•	Chief Officer
•	2nd Officer
•	3rd Officer
•	Chief Engineer
•	2nd Engineer
•	3rd Engineer
•	4th Engineer
•	5th Engineer
•	Electrical Officer
•	Gas Engineer
•	Deck Cadet
•	Engine Cadet
•	Bosun
•	AB
•	OS
•	Pumpman
•	Fitter
•	Motorman
•	Oiler
•	Wiper
•	Chief Cook
•	Messman
•	Junior Officer
Error Message:
"Invalid Assigned To value."
________________________________________
8. Approver
•	The Approver value should be the same as the Assigned To value.
________________________________________
9. Job Priority
Allowed values:
•	High
•	Medium
•	Low
Error Message:
"Invalid Job Priority."
________________________________________
10. Class Related
Accepted values:
•	Yes / No
•	Y / N
•	True / False
•	1 / 0
Any other value should be rejected.
Error Message:
"Invalid Class Related value."
________________________________________
11. Last Done Date
•	Date format must be DD-MM-YYYY.
•	Any invalid date or incorrect format should be rejected.
Error Message:
"Invalid Last Done Date. Expected format: DD-MM-YYYY."
________________________________________
12. Criticality
Accepted values:
•	Yes / No
•	Y / N
•	True / False
•	1 / 0
Error Message:
"Invalid Criticality value."
________________________________________
13. Is Active
Accepted values:
•	Yes / No
•	Y / N
•	True / False
•	1 / 0
Error Message:
"Invalid Is Active value."
