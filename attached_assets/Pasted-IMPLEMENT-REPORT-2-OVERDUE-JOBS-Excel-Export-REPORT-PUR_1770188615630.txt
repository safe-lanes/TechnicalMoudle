IMPLEMENT REPORT #2: OVERDUE JOBS - Excel Export

REPORT PURPOSE:
Generate an Excel report showing ALL overdue work orders that have passed their due dates and grace period. This is the HIGHEST PRIORITY report for class/ISM audits and PSC inspections. Overdue jobs represent non-compliance and safety risks.

CRITICAL REQUIREMENTS:
- This report MUST be sorted by most overdue first (highest priority)
- MUST highlight critical equipment overdue jobs prominently
- MUST show both calendar and running hours overdue calculations
- MUST be audit-ready with clear traceability

STEP 1 - CREATE BACKEND API ENDPOINT:

Location: Same file as Report #1
Route: POST /api/pms/reports/overdue-jobs
Request Body: {
  vesselId: string,
  asOfDate?: Date  // Optional, default to today
}

STEP 2 - DATABASE QUERY LOGIC:

Query the following tables with JOINS:
1. work_orders (main table)
2. components (JOIN on componentCode)
3. jobs (JOIN on jobId)
4. users (JOIN on assignedTo for assigned person name)

FILTERING CRITERIA - Include work orders where EITHER:

A. CALENDAR OVERDUE (Past grace period):
   - maintenanceBasis = 'Calendar' OR 'Calendar+RH'
   - dueDate < (TODAY - 7 days)  [Grace period is 7 days]
   - status NOT IN ('Completed', 'Postponed')

B. RUNNING HOURS OVERDUE (Past grace period):
   - maintenanceBasis = 'Running Hours' OR 'Calendar+RH'
   - currentCumulativeRH > (nextDueReading + 168 hours)  [Grace is 168 RH]
   - status NOT IN ('Completed', 'Postponed')

IMPORTANT: An overdue job is defined as one that has passed BOTH the due date/reading AND the grace period.

STEP 3 - CALCULATE DERIVED FIELDS:

For each overdue work order:

1. daysPastDue = Math.floor((TODAY - dueDate) / (1000 * 60 * 60 * 24)) - 7
   - Subtract 7 to account for grace period
   - If negative, set to 0

2. hoursPastDue = currentCumulativeRH - nextDueReading - 168
   - Subtract 168 to account for grace period
   - If negative, set to 0

3. overdueSeverity = Calculate severity level for sorting:
   - "CRITICAL" if (critical equipment = true) OR (daysPastDue > 30) OR (hoursPastDue > 720)
   - "SEVERE" if daysPastDue > 14 OR hoursPastDue > 336
   - "MODERATE" if daysPastDue > 7 OR hoursPastDue > 168
   - "MINOR" otherwise

4. overdueType = "Calendar" or "RH" or "Both" (if Calendar+RH basis)
