# Spares Import Validations

## 1. Duplicate Validation

* The combination of **Part Code + Component Code + Vessel Code** must be unique.
* The system should validate duplicates:

  * Within the import sheet.
  * Against existing records in the database.
* Duplicate records should not be imported and should be displayed in the Import Summary.

---

## 2. Component Code

* Component Code is mandatory and cannot be blank.
* The entered Component Code must exist in the selected vessel's Component List.

Error Messages:

* **"Component Code is mandatory."**
* **"Component Code does not exist for the selected vessel."**

---

## 3. Component Name

* Component Name should be auto-populated using the Component Code as a reference from the Component table.
* Any value provided in the import file should be ignored.

---

## 4. Part Name

* Part Name is mandatory.
* If the Part Name is blank, the record should not be imported.

Error Message:

* **"Part Name is mandatory."**

---

## 5. Maker Code

* The entered Maker Code must exist in the Maker List.
* If an invalid Maker Code is provided, the record should not be imported.

Error Message:

* **"Invalid Maker Code."**

---

## 6. Criticality

Accepted values:

* Yes / No
* Y / N
* True / False
* 1 / 0

Error Message:

* **"Invalid Criticality value."**

---

## 7. Is Active

Accepted values:

* Yes / No
* Y / N
* True / False
* 1 / 0

Error Message:

* **"Invalid Is Active value."**

---

## 8. IHM (Inventory of Hazardous Materials)

Accepted values:

* Yes / No
* Y / N
* True / False
* 1 / 0

Error Message:

* **"Invalid IHM value."**

---

## 9. Rotation Item

Accepted values:

* Yes / No
* Y / N
* True / False
* 1 / 0

Error Message:

* **"Invalid Rotation Item value."**

---

## 10. Location Validation

* If **Location A ROB** is entered, then **Location A** is mandatory.
* If **Location B ROB** is entered, then **Location B** is mandatory.
* The values entered for **Location A** and **Location B** must exist in the Location table for the selected vessel.

Error Messages:

* **"Location A is mandatory when Location A ROB is entered."**
* **"Location B is mandatory when Location B ROB is entered."**
* **"Invalid Location A."**
* **"Invalid Location B."**
