CRITICAL BUG: NEXT DUE RH CALCULATION IS COMPLETELY WRONG

PROBLEM IDENTIFIED:
Work Order: FO PURIFIER, OIL CHANGE - 250H
- Frequency: 250 Hours  
- Current Component RH: 2,001 hours
- Next Due RH shown: 250 Hours ← WRONG!
- Correct Next Due RH should be: 2,250 Hours (or 2,000 + 250)

ROOT CAUSE:
The system is storing "Next Due RH = 250" which is just the frequency value, NOT the actual next due running hour count.

CORRECT LOGIC:

Next Due RH = Last Completed RH + Frequency

Examples:
- Job never done before, component at 0 RH → Next Due RH = 0 + 250 = 250 RH
- Job completed at 250 RH, component now at 400 RH → Next Due RH = 250 + 250 = 500 RH  
- Job completed at 2000 RH, component now at 2001 RH → Next Due RH = 2000 + 250 = 2,250 RH

// One-time migration script
const rhWorkOrders = await WorkOrder.find({
  maintenanceBasis: "Running Hours",
  status: { $in: ["Planned", "Due", "Overdue"] }
});

for (const wo of rhWorkOrders) {
  const component = await Component.findById(wo.component);
  const currentRH = component.currentRunningHours;
  
  // Find last completed work order for this component/job
  const lastCompleted = await WorkOrder.findOne({
    component: wo.component,
    jobCode: wo.jobCode,
    status: "Completed"
  }).sort({ completedAt: -1 });
  
  if (lastCompleted && lastCompleted.completedAtRH) {
    wo.lastCompletedRH = lastCompleted.completedAtRH;
    wo.nextDueRH = lastCompleted.completedAtRH + wo.frequency;
  } else {
    // Never completed before - calculate from current RH
    const cyclesPassed = Math.floor(currentRH / wo.frequency);
    wo.lastCompletedRH = cyclesPassed * wo.frequency;
    wo.nextDueRH = (cyclesPassed + 1) * wo.frequency;
  }
  
  await wo.save();
  console.log(`Fixed WO ${wo.workOrderNo}: nextDueRH = ${wo.nextDueRH}`);
