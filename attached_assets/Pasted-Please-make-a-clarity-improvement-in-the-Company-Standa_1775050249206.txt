Please make a clarity improvement in the Company Standard Settings popup.

Problem to fix
The popup is now tab-based, with separate tabs for:

Calendar-Based Jobs

Running Hours Based Jobs

This is the correct direction because it keeps the settings clean and allows each job type to be configured separately. The page also already shows separate company-standard summaries like Cal Lead / Cal Grace / RH Lead / RH Grace, so the system is clearly distinguishing between calendar-based and RH-based settings.

However, inside each tab, the current Scope labels can still create confusion.

For example:

“Apply to all Work Orders”

“Apply only to WOs due in last week of month”

The phrase “all Work Orders” can be misunderstood by users as:

all work orders in the PMS, including both Calendar-based and RH-based,
when in reality the scope must apply only to the work order type of the currently selected tab.

Required business interpretation
The settings in each tab must be exclusively applicable only to that tab’s work-order type.

Meaning:

In Calendar-Based Jobs tab
If user selects:

Apply to all Work Orders

it must mean:

Apply to all Calendar-Based Work Orders only

and not to RH-based work orders

In Running Hours Based Jobs tab
If user selects:

Apply to all Work Orders

it must mean:

Apply to all Running Hours Based Work Orders only

and not to Calendar-based work orders

This distinction must be very clear in the UI language so there is no ambiguity.

What to change
Please update the labels and helper text inside both tabs so the user immediately understands that the scope is tab-specific.

Calendar tab label changes
In Calendar-Based Jobs tab, change scope labels to calendar-specific wording.

Instead of:

Apply to all Work Orders

Use something like:

Apply to all Calendar-Based Work Orders

Instead of:

Apply only to WOs due in last week of month

Use something like:

Apply only to Calendar-Based WOs due in last week of month

Also update the helper descriptions below them accordingly, for example:

“The selected grace method applies to all calendar-based work orders”

“The selected grace method applies only to calendar-based work orders due in the last 7 days of the month”

RH tab label changes
In Running Hours Based Jobs tab, change scope labels to RH-specific wording.

Instead of:

Apply to all Work Orders

Use something like:

Apply to all Running Hours Based Work Orders

Instead of:

Apply only to WOs due in last week of month

Use something like:

Apply only to RH-Based WOs due in last week of month

Or, if that wording feels too long, use:

Apply to all RH-Based Work Orders

Apply only to RH-Based WOs due in last week of month

Also update the helper descriptions below them accordingly, for example:

“The selected grace method applies to all running-hours-based work orders”

“The selected grace method applies only to running-hours-based work orders due in the last 7 days of the month”

Important wording rule
Do not use generic wording like:

all Work Orders

all WOs

inside a tab if it can be interpreted across both job types.

Every scope label should make it explicit whether it refers to:

Calendar-Based WOs
or

Running Hours Based WOs

Also review the fallback section wording
Please also check the fallback section text in each tab.

For example, where it currently says things like:

“Fallback for WOs not due in last week of month”

make it type-specific as well.

In Calendar tab
Use:

Fallback for Calendar-Based WOs not due in last week of month

In RH tab
Use:

Fallback for RH-Based WOs not due in last week of month
or

Fallback for Running Hours Based WOs not due in last week of month

The description text under fallback should also be type-specific.

UX expectation
This is mainly a clarity and business-language fix, not a structural redesign.

Do not change:

the tab-based layout,

the save logic,

the field structure,

the separation between Calendar and RH sections.

Just make the labels and descriptive text precise enough that users never think “all” means both tabs together.

Final intent
After this change:

settings in Calendar-Based Jobs tab clearly apply only to calendar-based work orders,

settings in Running Hours Based Jobs tab clearly apply only to RH-based work orders,

the word “all” should no longer create confusion,

the popup should communicate exclusive applicability by wording alone.

Acceptance criteria
This task is done when:

Calendar tab scope labels explicitly say they apply only to calendar-based WOs

RH tab scope labels explicitly say they apply only to RH-based WOs

Helper texts are updated accordingly

Fallback section labels are also updated to be type-specific

No user can misread “all work orders” as meaning both calendar and RH together
