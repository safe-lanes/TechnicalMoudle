Current Problem
The "IHM Inventory Status Report" in /pms/reports currently only downloads a basic PDF. We need a full interactive report page similar to the existing StoresInventoryStatusReport.tsx, but specifically for IHM (Inventory of Hazardous Materials) compliance tracking.

Data Sources & Schema
1. Spares Table (db/schema/spares.ts):

Fields needed: partCode, partName, component, partNumber, rob, minStock, location, ihm (Yes/No/Unknown), evidenceType, notes, vesselId, uom

IHM field mapping: ihm field → "Yes" = present, "No" = not_present, null/undefined = unknown

2. Stores Table (db/schema/storesItems.ts):

Fields needed: itemCode, itemName, storesCategory, rob, minStock, location, ihmPresence (Unknown/Present/Not Present), ihmEvidenceType, notes, vesselId, uom

IHM field mapping: ihmPresence field → direct mapping to present/not_present/unknown

Backend Implementation
Create API Route: server/routes/reports.ts

Add endpoint: GET /api/reports/ihm-inventory-status

Query Parameters:

typescript
{
  vesselId?: number;        // Filter by vessel
  ihmStatus?: 'present' | 'not_present' | 'unknown' | 'all';  // Filter by IHM status
  itemType?: 'spare' | 'store' | 'all';   // Filter by source
  evidenceType?: string;    // Filter by evidence type
  search?: string;          // Search in code/name/component
  page?: number;            // Pagination (default: 1)
  pageSize?: number;        // Items per page (default: 50)
  sortBy?: string;          // Column to sort by
  sortOrder?: 'asc' | 'desc';  // Sort direction
}
Response Schema:

typescript
{
  summary: {
    totalItems: number;
    ihmPresent: number;     // Count of items with IHM present
    noIhm: number;          // Count of items with no IHM
    unknown: number;        // Count of items with unknown status
  };
  items: Array<{
    id: number;
    itemCode: string;
    itemName: string;
    itemType: 'spare' | 'store';
    componentOrCategory: string;  // Component name for spares, category for stores
    ihmStatus: 'present' | 'not_present' | 'unknown';
    evidenceType: string | null;
    currentROB: number;
    minStock: number;
    location: string;
    uom: string;
    notes: string | null;
  }>;
  pagination: {
    currentPage: number;
    totalPages: number;
    totalItems: number;
    pageSize: number;
  };
  categoryCounts: {
    all: number;
    spares: number;
    stores: number;
  };
}
Implementation Logic:

Fetch data from both spares and storesItems tables

Normalize IHM status values to common format (present/not_present/unknown)

Combine results with itemType field to distinguish source

Apply filters (vesselId, ihmStatus, itemType, search)

Apply sorting

Apply pagination

Calculate summary statistics and category counts
