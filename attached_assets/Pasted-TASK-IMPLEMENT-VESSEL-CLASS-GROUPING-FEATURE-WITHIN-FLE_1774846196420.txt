TASK: IMPLEMENT VESSEL CLASS / GROUPING FEATURE WITHIN FLEET (DRAG & DROP)

Objective:

Introduce a **Class / Grouping feature within Fleet**, allowing vessels to be organized into logical groups (classes) using **drag-and-drop functionality**.

--------------------------------------------------

1. Concept Definition

• A **Fleet** contains multiple vessels  
• Within a Fleet, vessels can be grouped into:
  - Classes  
  - Groups  

• A **Class/Group** is a logical container for vessels (e.g., Tankers, Bulk Carriers, Offshore, etc.)

--------------------------------------------------

2. Functional Requirement

A. Create Class / Group

• Ability to create multiple **Classes/Groups** under a Fleet  
• Each Class should have:
  - Class Name  
  - Optional Description  

--------------------------------------------------

B. Vessel Assignment

• Vessels under a Fleet should be assignable to a Class  

Assignment Method:

• Drag and Drop vessel from:
  - Fleet (unassigned list) → into a Class  
  - One Class → another Class  

--------------------------------------------------

3. Drag and Drop Behavior

• User can drag vessel from Fleet list  
• Drop into a specific Class/Group  

On Drop:

• Update vessel mapping:
  - vessel_id → class_id  

--------------------------------------------------

4. UI Structure

Fleet View:

• Fleet  
  ├── Unassigned Vessels  
  ├── Class / Group 1  
  │     ├── Vessel A  
  │     ├── Vessel B  
  ├── Class / Group 2  
        ├── Vessel C  

--------------------------------------------------

5. Data Model Changes

Introduce new structure:

Table: Fleet_Classes
• class_id  
• fleet_id  
• class_name  
Vessel_id
Vessel_name
• description  

Update Vessel Table:

• Add:
  class_id (nullable)

--------------------------------------------------

6. Rules

• A vessel belongs to only **one class at a time**  
• Vessel must belong to a Fleet  
• Class must belong to a Fleet  

--------------------------------------------------

7. Validation

• Prevent cross-fleet drag/drop  
• Allow re-assignment between classes within same fleet  
• Allow unassigned state (optional)  

--------------------------------------------------

8. Persistence Logic

On drag-drop:

UPDATE vessels  
SET class_id = selected_class_id  
WHERE vessel_id = dragged_vessel_id  

--------------------------------------------------

9. Additional Features (Optional)

• Rename Class  
• Delete Class (with vessel reassignment handling)  
• View vessels by class filter  

--------------------------------------------------

10. Expected Result

• Fleet contains grouped vessel structure  
• Users can organize vessels into classes  
• Drag-and-drop works seamlessly  
• Clean hierarchical visualization of fleet → class → vessels
