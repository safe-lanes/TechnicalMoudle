CREATE IHM INVENTORY STATUS REPORT

Report Name: IHM Inventory Status Report
Location: /pms/reports/ihm-inventory-status
Report Type: Quarterly, HIGH Priority

OBJECTIVE:
Create a comprehensive IHM (Inventory of Hazardous Materials) Inventory Status Report that provides a complete inventory of all items (spares and stores/chemicals) with their hazardous material presence status and evidence documentation. This report is critical for IMO Hong Kong Convention compliance and EU Ship Recycling Regulation.

DATA SOURCES:
1. Spares table - with IHM column
2. Stores table (Stores, Lubes, Chemicals, Others) - with ihm_presence and ihm_evidence_type fields
3. Components table - for component relationships
4. Vessels table - for vessel information

REPORT REQUIREMENTS:

1. SUMMARY SECTION (Top Cards):
   - Total Items: Count of all spares + stores items
   - IHM Present: Count where IHM = 'Yes' or ihm_presence = 'Present'
   - No IHM: Count where IHM = 'No' or ihm_presence = 'Not Present'
   - Unknown: Count where IHM status is 'Unknown' or NULL

2. FILTERS:
   - Vessel selector (dropdown)
   - Date range selector
   - IHM Status filter (All, Present, Not Present, Unknown)
   - Item Type filter (Spares, Stores, Lubes, Chemicals, Others, All)
   - Component/Category filter

3. DETAILED TABLE with columns:
   - Item Code
   - Item Name/Description
   - Item Type (Spare/Store/Chemical/Lube/Other)
   - Component/Equipment (linked component name)
   - Location (physical location on vessel)
   - Part Number / Chemical Code
   - IHM Presence Status (Present/Not Present/Unknown)
   - IHM Evidence Type (Certificate/Declaration/SDS/Material Declaration/None)
   - Hazard Classification (if applicable)
   - SDS Reference (if applicable)
   - Current ROB/Stock
   - UOM
   - Last Updated Date

4. GROUPING & SORTING:
   - Primary grouping by Component Category (from SFI codes)
   - Secondary sorting by IHM status (Present first, then Unknown, then Not Present)
   - Tertiary sorting by Item Name alphabetically

5. EXPORT FUNCTIONALITY:
   - PDF export with vessel letterhead
   - Excel export with all details
   - Include report generation timestamp
   - Include vessel name and IMO number
   - Include reporting date range

6. DATA LOGIC:
   - Combine data from both Spares AND Stores tables
   - For Spares: use the 'ihm' column (likely boolean or string)
   - For Stores/Chemicals: use 'ihm_presence' and 'ihm_evidence_type' columns
   - Map component relationships to show which equipment items belong to
   - Handle NULL values as "Unknown" status

7. VISUAL ENHANCEMENTS:
   - Color coding: Red for "IHM Present", Green for "No IHM", Yellow for "Unknown"
   - Progress indicators showing compliance percentage
   - Warning icons for items with "Unknown" status
   - Badge indicators for evidence type

8. ADDITIONAL FEATURES:
   - Search functionality across all columns
   - Pagination (50/100/200 items per page)
   - Quick stats showing % of inventory with documented IHM status
   - Downloadable evidence documentation links (future enhancement placeholder)

DATABASE QUERIES NEEDED:
- Query spares table: SELECT * FROM spares WHERE vessel_id = ? AND ihm IS NOT NULL
- Query stores tables: SELECT * FROM stores WHERE vessel_id = ? (union with chemicals, lubes, others)
- Join with components table to get equipment names
- Aggregate counts for summary cards

COMPLIANCE NOTES:
This report helps vessels comply with:
- IMO Hong Kong Convention for Safe and Environmentally Sound Recycling of Ships
- EU Ship Recycling Regulation (EU SRR)
- Classification society requirements for IHM Part I documentation

The report should be generated quarterly but can be run on-demand for audits and inspections.
