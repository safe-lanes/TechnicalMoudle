══════════ THE 7 MVP EVALUATORS ══════════
(objectType, friendly payload, vesselId set on every alert. priority lowercase.)
1. certificate_expiration  (REUSE existing stub type/label/drawer branch) — source getAllVesselCertificateData()
   d=daysDiff(expiry_date); for each tier T in t.leadDaysTiers(default [90,30]): if 0<=d<=T → emit,
   priority = T<=t.highAtDays(30) ? 'high':'medium'; skip if d<0. dedupe `cert_expiring:<vcdId>:<T>`.
2. certificate_expired — getAllVesselCertificateData(); daysDiff(expiry_date)<0 → emit; 'high';
   dedupe `cert_expired:<vcdId>`.
3. survey_due_soon — getAllVesselSurveyData() (filter is_deleted); 0<=daysDiff(due_date)<=t.leadDays(30) →
   emit; 'medium'; dedupe `survey_due_soon:<vsdId>`.
4. survey_window_closing — second_range_date present; 0<=daysDiff(second_range_date)<=t.leadDays(30) → emit;
   'high'; dedupe `survey_window_closing:<vsdId>`.
5. survey_overdue — daysDiff(second_range_date ?? due_date)<0 → emit; 'high'; dedupe `survey_overdue:<vsdId>`.
6. defect_overdue — getDefects(); NOT done (rule C) AND target_close_date present AND daysDiff(target_close_date)<0
   → emit; 'high'; dedupe `defect_overdue:<defectId>`.
7. defect_coc — getDefects(); (rule B) AND NOT done (rule C) → emit; 'high'; dedupe `defect_coc:<defectId>`.
