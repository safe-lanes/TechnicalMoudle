TASK: ADD EXPORT OPTIONS POPUP – SPARES SECTION (INVENTORY TAB)

Objective:

Enhance the **Export functionality in Spares section (Inventory Tab)** by adding a **popup with two export options**, each generating data in specific formats.

--------------------------------------------------

Requirement:

When user clicks on **Export button**:

• A popup should appear (UI similar to reference screenshot)  
• Popup must contain 2 options:

  1. Export Unique Spares  
  2. Export Component Spares  

--------------------------------------------------

Option 1: Export Unique Spares

Functionality:

• Export all **unique spares** for the **selected vessel**  
• Data source: **Spares table**  

Export Format:

• Excel format must match **Spares Import Template**  
• Headers, column order, and structure must be identical  

Validation:

• Only spares belonging to the selected vessel should be exported  
• No duplicate entries  

--------------------------------------------------

Option 2: Export Component Spares

Functionality:

• Export all **component-wise spare distribution** for the **selected vessel**  
• Data source: **Spare_Component_Linkage table**  

Export Format:

• Excel format must match **Spares Bulk Import Template**  
• Include component-wise mapping fields exactly as import format  

Validation:

• Only linkages for selected vessel should be exported  
• Each row should represent one Spare–Component mapping  
• Data count should match linkage table records  

--------------------------------------------------

UI Requirements:

• Popup should open on Export button click  
• Remove direct export action (must go through popup)  
• Place both options clearly with selectable action  
• Add Export confirmation trigger after selection  

--------------------------------------------------

Implementation Notes:

• Reuse existing export service where possible  
• Ensure both exports are independent and correctly mapped to respective tables  
• Maintain consistent file naming convention  

--------------------------------------------------

Expected Result:

• Export button opens a popup with two options  
• Each option exports correct dataset  
• Excel formats match respective import templates exactly  
• Data is filtered by selected vessel
