TASK: IMPLEMENT IMPORT PROGRESS LOADER WITH SCREEN LOCK – ALL BULK IMPORT SCREENS

Objective:

Enhance all **Bulk Import screens** by adding a **post dry-run progress loader** with detailed execution tracking and restricting user interaction during import.

--------------------------------------------------

Trigger Point:

• After successful **Dry Run validation**  
• When user clicks on **Final Import / Proceed Import**

--------------------------------------------------

Loader Requirements:

Display a full-screen loader with the following details:

1. Progress Indicator

• Percentage completion (e.g., 0% → 100%)  
• Progress bar (visual representation)

2. Record Processing Details

• Total number of records  
• Number of records processed  
• Number of records remaining  

Example:

• Total Records: 1000  
• Completed: 450  
• Remaining: 550  

3. Status Message

• Dynamic status updates such as:
  - “Initializing Import…”  
  - “Processing Records…”  
  - “Finalizing…”  

--------------------------------------------------

Screen Behavior:

• Entire screen should be **frozen / disabled** during import  
• User should NOT be able to:
  - Navigate to other modules  
  - Click sidebar/menu  
  - Refresh-trigger actions  
  - Trigger another import  

• Prevent accidental interruption of import process  

--------------------------------------------------

Scope:

• Apply this functionality to **ALL Bulk Import screens**, including but not limited to:

  - Components Import  
  - Spares Import  
  - Jobs Import  
  - Stores Import  
  - Any other bulk upload modules  

--------------------------------------------------

Technical Behavior:

• Progress should be updated in real-time based on backend processing  
• Use batch processing or streaming updates if required  
• Ensure accurate count tracking (processed vs remaining)  

--------------------------------------------------

Failure Handling:

• If any record fails during import:
  - Show error count  
  - Continue processing remaining records (if applicable)  
  - Provide summary after completion  

--------------------------------------------------

Completion State:

After import completion:

• Show success message with:
  - Total processed  
  - Successful records  
  - Failed records  

• Provide option to:
  - Download error report (if failures exist)  
  - Close loader  

--------------------------------------------------

Expected Result:

• User sees real-time progress during import  
• Screen remains locked until process completes  
• No navigation or interference during import  
• Clear visibility of import status and record counts  
• Consistent behavior across all bulk import modules
