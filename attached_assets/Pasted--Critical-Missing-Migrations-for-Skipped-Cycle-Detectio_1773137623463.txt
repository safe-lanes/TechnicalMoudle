FROM information_schema.columns

### STEP 2: Add to the Existing Migration System

For each column confirmed MISSING, add a new migration entry into 
`server/migrations.ts` following the EXACT same pattern as the 52 existing entries.

Each migration must:
1. Have a unique sequential name (e.g., migration_053, migration_054...)
2. Use `IF NOT EXISTS` guard or check column existence before ALTER TABLE
3. Be IDEMPOTENT — safe to run multiple times without error
4. Log clearly when applied vs skipped

Example pattern to follow:
```typescript
{
  name: 'add_missed_cycles_to_work_orders',
  async up(db) {
    // Check if column exists first
    const result = await db.execute(sql`
      SELECT COUNT(*) as cnt 
      FROM information_schema.columns 
      WHERE table_name = 'work_orders' 
        AND column_name = 'missed_cycles'
    `);
    if (result.rows[0].cnt === '0') {
      await db.execute(sql`
        ALTER TABLE work_orders 
        ADD COLUMN missed_cycles INTEGER DEFAULT 0
      `);
      console.log('[MIGRATION] Added missed_cycles to work_orders');
    } else {
      console.log('[MIGRATION] Skipped: missed_cycles already exists in work_orders');
    }
  }
}
```

Add one migration entry per column (or group same-table columns into one migration).
