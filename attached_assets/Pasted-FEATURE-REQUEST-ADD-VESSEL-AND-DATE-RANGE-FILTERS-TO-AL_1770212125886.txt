FEATURE REQUEST: ADD VESSEL AND DATE RANGE FILTERS TO ALL REPORT CATEGORY PAGES

CURRENT SITUATION:
The main Reports page (/pms/reports) has the following filters:
1. Search box ("Search reports...")
2. Vessel dropdown ("All Vessels")
3. Date Range picker ("Select date range")
4. Clear button

However, when users click into any report category (e.g., "Maintenance & Work Orders", "Maintenance Planner", "Running Hours & Condition", etc.), these pages are missing the critical filters:
- MISSING: Vessel dropdown filter
- MISSING: Date Range picker
- MISSING: Clear button

The category pages only have:
- Search box (for searching within that category)
- Category-specific filters (like "All Frequencies", "All Priorities")

PROBLEM:
Users cannot select the vessel or date range before generating reports. The system appears to use default values (current vessel and current month), which leads to:
- Reports showing wrong data (e.g., Monthly Maintenance Summary showing 0 completed jobs because date range isn't set properly)
- Users cannot generate reports for different vessels
- Users cannot generate reports for specific date ranges
