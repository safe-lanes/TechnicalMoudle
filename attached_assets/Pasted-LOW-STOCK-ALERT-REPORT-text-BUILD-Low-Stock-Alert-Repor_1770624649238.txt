BUILD: Low Stock Alert Report - Daily/Weekly Monitoring

OBJECTIVE:
Create a comprehensive "Low Stock Alert Report" that identifies items below minimum levels requiring immediate attention. This is a HIGH priority report that runs Daily/Weekly to ensure critical supplies don't run out.

1. **Stores Items** (Stores, Lubes, Chemicals) have:
   - Item Code, Item Name, Category/Type
   - ROB (Remaining on Board - current stock)
   - Min (Minimum stock level)
   - Stock Status (OK/Low badge) - Already calculated!
   - Location, UOM, Supplier info

2. **Transaction History** (ledger table):
   - Event types: INITIAL, RECEIVE, CONSUME, ADJUSTMENT
   - Qty Change, ROB After, Date
   - Allows calculation of consumption rates

3. **Identified Low Stock Items (Current):**
   - Stores: IT-0004 (Cutting Disc) - ROB: 0, Min: 6
   - Lubes: LU-0004 (Turbocharger Lube Oil) - ROB: 0, Min: 6
   - Chemicals: CH-0004 (Cooling Water Treatment) - ROB: 0, Min: 6

**Stock Status Logic (Already Implemented):**
- Low: ROB ≤ Min (items at or below minimum)
- OK: ROB > Min

- `location` - Filter by location

**Response Structure:**
```json
{
  "summary": {
    "totalLowStock": 25,
    "criticalItems": 10,
    "highPriorityItems": 8,
    "mediumPriorityItems": 7,
    "storesCount": 12,
    "lubesCount": 8,
    "chemicalsCount": 5
  },
  "items": [
    {
      "id": "...",
      "itemCode": "IT-0004",
      "itemName": "Cutting Disc (Angle Grinder)",
      "itemType": "stores",
      "category": "Mechanical",
      "rob": 0,
      "minStock": 6,
      "maxStock": 20,
      "deficit": 6,
      "uom": "pcs",
      "location": "@ 0 / 0",
      "priority": "Critical",
      "lastConsumedDate": "2026-01-15",
      "avgMonthlyConsumption": 3.5,
      "daysUntilStockout": 0,
      "estimatedCost": 450,
      "supplier": "ABC Marine Supplies",
      "leadTime": "2 weeks"
    }
  ]
}
Calculations Required:

Deficit: deficit = minStock - rob (how many units needed to reach minimum)

Priority Level:

Critical: ROB = 0 (completely out of stock)

High: ROB > 0 AND ROB < (Min * 0.5) (less than 50% of minimum)

Medium: ROB >= (Min * 0.5) AND ROB <= Min (50%-100% of minimum)

Average Monthly Consumption:

Query last 90 days of CONSUME events from ledger

Calculate: SUM(qty_change where event='CONSUME') / 3 (divide by 3 months)

Days Until Stockout:

If avgMonthlyConsumption > 0:

daysUntilStockout = (ROB / (avgMonthlyConsumption / 30))

If ROB = 0: daysUntilStockout = 0

If no consumption data: daysUntilStockout = null

Estimated Cost:

estimatedCost = deficit × unitCost

If unitCost is null, show "N/A"
