CRITICAL ISSUES FOUND IN RUNNING HOURS SYSTEM - COMPREHENSIVE FIX REQUIRED

PROBLEM SUMMARY:
The Running Hours (RH) system has multiple data integrity issues:

1. ✗ Work order completion allows entering RH values HIGHER than actual component RH
2. ✗ lastDoneRH values have no traceable source (hardcoded during job creation)
3. ✗ No validation during Part B completion to check entered RH against component's actual RH
4. ✗ Component RH and Work Order RH can diverge, causing incorrect due date calculations

DETAILED ISSUES:

ISSUE 1: NO VALIDATION DURING WORK ORDER COMPLETION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Example from audit trail:
- Component: FO Purifier No.2 (702.005.02)
- Component RH updated to: 870 hours (March 11, 2026 at 11:22:56)
- Work Order completed 1 minute later (11:23:53)
- Current Reading entered in WO: 890 hours ← INVALID! 20 hours higher than actual!

WHAT'S WRONG:
The Part B completion form accepted current_reading = 890 even though the component's actual RH was only 870. This creates false data.

ISSUE 2: UNTRACEABLE lastDoneRH VALUES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Example:
- Job: FO Purifier No.1 (component 9e70b92d)
- lastDoneRH: 2000 hours
- Source: Hardcoded when job record was created (March 6, 2026)
- No completed work orders exist for this job
- No import logs or audit trail showing where 2000 came from
- Component ID doesn't even exist in components table anymore

WHAT'S WRONG:
Initial lastDoneRH values are unverifiable and likely incorrect, leading to wrong nextDueRH calculations.

ISSUE 3: CONSEQUENCES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Bad RH data causes:
- Incorrect nextDueRH calculations (showing 250 RH when should be 2,250 RH)
- Jobs appearing in wrong status tabs (Due/Overdue/Planned)

- Loss of maintenance schedule integrity

// In Part B completion handler - B3. Running Hours validation

async function validateRunningHoursReading(workOrderId, enteredReading) {
  const workOrder = await WorkOrder.findById(workOrderId).populate('component');
  const component = workOrder.component;
  
  // Get actual component RH from Running Hours module
  const actualComponentRH = component.currentRunningHours;
  
  // VALIDATION RULES:
  
  // Rule 1: Entered reading cannot be HIGHER than actual component RH
  if (enteredReading > actualComponentRH) {
    throw new Error(
      `Invalid Running Hours: You entered ${enteredReading} hours, but the component's actual running hours is only ${actualComponentRH} hours. ` +
      `Please update the component's running hours first in the Running Hours module.`
    );
  }
  
  // Rule 2: Entered reading should be within reasonable range (not too old)
  const tolerance = workOrder.frequency * 0.5; // Allow up to half a maintenance cycle back
  const minAcceptableRH = Math.max(0, actualComponentRH - tolerance);
  
  if (enteredReading < minAcceptableRH) {
    // Warning but allow (user might be completing delayed maintenance)
    console.warn(
      `Warning: Entered RH (${enteredReading}) is ${actualComponentRH - enteredReading} hours behind current RH (${actualComponentRH})`
    );
  }
  
  // Rule 3: For RH-based jobs, current reading should be >= last done RH
  const jobRecord = await Job.findOne({ 
    component: component._id,
    jobCode: workOrder.jobCode 
  });
  
  if (jobRecord && jobRecord.lastDoneRH && enteredReading < jobRecord.lastDoneRH) {
    throw new Error(
      `Invalid Running Hours: You entered ${enteredReading} hours, but this job was last done at ${jobRecord.lastDoneRH} hours. ` +
      `Running hours cannot go backwards.`
    );
  }
  
  return true;
}

// Migration script: fix-rh-job-last-done.js

async function fixInvalidLastDoneRH() {
  const vessel = 'Vessel 11';
  
  console.log('Starting RH job data cleanup...');
  
  // Get all RH-based jobs
  const rhJobs = await Job.find({
    vessel: vessel,
    maintenanceBasis: 'Running Hours'
  }).populate('component');
  
  for (const job of rhJobs) {
    const component = job.component;
    
    if (!component) {
      console.log(`⚠️ Job ${job.jobCode} has invalid component reference - skipping`);
      continue;
    }
    
    const currentComponentRH = component.currentRunningHours || 0;
    
    // Strategy 1: Find last completed work order for this job
    const lastCompletedWO = await WorkOrder.findOne({
      component: component._id,
      jobCode: job.jobCode,
      status: 'Completed'
    })
    .sort({ completedAt: -1 })
    .select('completedAtRH currentReading completedAt');
    
    if (lastCompletedWO && lastCompletedWO.completedAtRH) {
      // We have a verified completion - use it
      job.lastDoneRH = lastCompletedWO.completedAtRH;
      console.log(`✓ ${job.jobCode}: Set lastDoneRH = ${job.lastDoneRH} from completed WO`);
    }
    else if (job.lastDoneRH > currentComponentRH) {
      // lastDoneRH is higher than current component RH - INVALID!
      // Reset to nearest lower cycle
      const cycle = job.frequency;
      const estimatedLastDone = Math.floor(currentComponentRH / cycle) * cycle;
      
      console.log(`⚠️ ${job.jobCode}: lastDoneRH (${job.lastDoneRH}) > current RH (${currentComponentRH})`);
      console.log(`   Resetting to ${estimatedLastDone} (nearest completed cycle)`);
      
      job.lastDoneRH = estimatedLastDone;
    }
    else if (job.lastDoneRH === null || job.lastDoneRH === undefined) {
      // Never done - set to 0
      job.lastDoneRH = 0;
      console.log(`ℹ️ ${job.jobCode}: No lastDoneRH - setting to 0 (first cycle)`);
    }
    else {
      // lastDoneRH looks reasonable - keep it but verify
      console.log(`✓ ${job.jobCode}: Keeping lastDoneRH = ${job.lastDoneRH} (within valid range)`);
    }
    
    // Recalculate nextDueRH
    job.nextDueRH = job.lastDoneRH + job.frequency;
    
    await job.save();
  }
  
  console.log('✅ RH job cleanup completed');
}
