══════════ MVP SCOPE — 7 alert types (build these; per-alert spec is exact) ══════════
For all: source rows are vessel-scoped already; set objectType, objectId (the row id), vesselId; payload should
include a human label (e.g. certName/surveyName/defect title + the date + computed days). recipients (all 7) =
{"roles":["Ship","Office","PMS Admin","Sail Admin","Super Admin","Vessel Admin"]}. seed enabled=false.
 
1. certificate_expiration  (REUSE existing stub type/label/drawer branch) — "Certificate Expiring Soon"
   source getCertificates(); d = daysDiff(expiry_date). For each tier T in thresholds.leadDaysTiers (default
   [90,30]): if d >= 0 AND d <= T → emit. priority = (T <= thresholds.highAtDays(default 30)) ? 'high' : 'medium'.
   Skip if d < 0 (that's certificate_expired). dedupeKey `cert_expiring:<certId>:<T>`. thresholds
   '{"leadDaysTiers":[90,30],"highAtDays":30}'.
2. certificate_expired — "Certificate Expired"
   getCertificates(); daysDiff(expiry_date) < 0 → emit. priority 'high'. dedupeKey `cert_expired:<certId>`.
   thresholds '{}'.
3. survey_due_soon — "Survey Due Soon"
   getSurveys() (is_active, applicable, not deleted); d = daysDiff(due_date); 0 <= d <= thresholds.leadDays(30)
   → emit. priority 'medium'. dedupeKey `survey_due_soon:<surveyId>`. thresholds '{"leadDays":30}'.
4. survey_window_closing — "Survey Window Closing"
   getSurveys() filtered as above; only if second_range_date present; d = daysDiff(second_range_date);
   0 <= d <= thresholds.leadDays(30) → emit. priority 'high'. dedupeKey `survey_window_closing:<surveyId>`.
   thresholds '{"leadDays":30}'.
5. survey_overdue — "Survey Overdue"
   getSurveys() filtered as above; overdue when daysDiff(second_range_date ?? due_date) < 0 → emit.
   priority 'high'. dedupeKey `survey_overdue:<surveyId>`. thresholds '{}'.
6. defect_overdue — "Defect Overdue"
   getDefects(); status NOT IN ('closed','cancelled') (case-insensitive) AND target_close_date present AND
   daysDiff(target_close_date) < 0 → emit. priority 'high'. dedupeKey `defect_overdue:<defectId>`. thresholds '{}'.
7. defect_coc — "COC / Class Defect Raised"
   getDefects(); (is_coc = true OR upper(category) = 'COC') AND status NOT IN ('closed','cancelled') → emit.
   priority 'high'. dedupeKey `defect_coc:<defectId>`. thresholds '{}'.
