🔍 Your Task
Identify and explain every part of the system that deals with reading or writing stored data, including:
1. What is the current persistent storage?
•	Identify which file or files are used as persistent storage (e.g., test-data.json or others).
•	Show exact file paths.
•	Explain what type of data each file stores.
•	Show how the file is loaded, read, parsed, and updated at runtime.
2. Which files implement the storage logic?
Analyze and document:
•	persistentFileStorage implementation
•	localFileStorage.ts
•	persistentStorage.ts
•	storage.ts (interfaces / abstraction layer)
•	Any helper utilities, wrappers, or intermediate layers
For each file:
•	Explain its purpose
•	Show which methods it exposes
•	Show which methods handle read/write
•	Show how errors, concurrency, or overwriting are handled
3. Which parts of the backend use this storage?
Scan the entire backend and list:
•	Every service (inside /server/services/*) that calls storage methods
•	Every route handler (inside /server/routes/*) that reads/writes data
•	Any initialization or bootstrap logic touching storage (like initData.ts, if present)
For each usage:
•	Include file path
•	Function name
•	What it reads/writes
•	Whether it reads all data, a section of data, or writes back the entire JSON
4. How is stored data sent to the UI?
Explain exactly how persistent storage data flows to the frontend UI.
For example:
•	Which backend routes return stored data
•	How those routes fetch the data from storage
•	Which frontend services call those backend routes
•	Which React components use those services to show stored data in the UI
Include:
•	Backend file paths
•	Frontend file paths
•	Request→response→UI rendering flow
5. How UI triggers storage writes
Explain how user actions cause persistent storage to update:
•	Which UI components submit changes
•	Which frontend service sends updated data
•	Which backend route receives it
•	Which storage function writes it to persistent storage
Show detailed file paths and call flow.
6. Identify any caching layers
If any part of the project:
•	Loads storage into memory
•	Caches JSON data
•	Keeps global state
•	Reduces disk reads/writes
