Context

In Bulk Data Import → Fleet Data Import, when the user selects Fleet Spares, an Excel template is used to bulk import Fleet-level spare part master data.

Currently:

There is no dedicated or clearly enforced table for Fleet Spares data

Import behavior must be standardized and aligned with Fleet Jobs importing logic

Core Requirement

When Fleet Spares option is selected:

Imported data must be saved only in a new table named fleet_spares

If the fleet_spares table does not exist:

It must be created first

The table must include:

All mandatory system columns

All columns from the Fleet Spares Import Template

The importing process must follow the same pattern as Fleet Jobs importing

Validation

Final commit

Part Code

Fleet Equipment Code

Fleet Equipment Name

Part Name

Is Active

If any of the above fields are missing or blank:

The record must be marked as invalid

Clear validation messages must be shown

Import must not proceed for invalid records
