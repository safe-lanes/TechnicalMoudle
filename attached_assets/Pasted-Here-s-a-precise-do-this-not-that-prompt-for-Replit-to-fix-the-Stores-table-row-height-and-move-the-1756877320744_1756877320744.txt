# Prompt: Compact single-row layout for Stores table + move action icons to last column

## What I want

In **PMS → Stores → Inventory** the table currently shows the action icons (edit / view / add / delete, etc.) in a *second line* inside the first column. That makes each row tall and the table looks bulky.

**Fix it** so that:

1. **Every item is a single compact row** (no line breaks created by the action icons).
2. The **action icons appear in a dedicated “Actions” column at the far right**, aligned on one line.
3. Rows maintain standard height (middle-aligned content), and icons never wrap to a new line.
4. On small screens, actions can collapse into a kebab “⋮” menu.

> Do **not** change the data order of existing columns. Only add a new last column for actions and move the icon buttons there.

---

## Where to change

Find the Stores inventory table component (search codebase for any of these):

* `"Stores Inventory"` header, or columns: `"Item Code","Item Name","UOM","ROB","Min","Stock","Location","IHM"`.
* Common filenames might be: `StoresTable`, `StoresInventory`, `StoresList`, `.tsx/.jsx/.vue`.

You will see the icon buttons currently rendered inside the **Item Code** cell or a leading cell. **Remove them from there** and render them into the last “Actions” column.

## Required structural changes

### 1) Add a last column header

```jsx
// After the existing <th>IHM</th>
<th className="w-1 whitespace-nowrap text-right pr-3">Actions</th>
```

### 2) Render actions into the last cell of each row

```jsx
<tr key={row.id} className="align-middle">
  {/* ...existing tds for Item Code → IHM... */}

  <td className="actions-cell text-right pr-3">
    <div className="actions-inline">
      {/* Keep the same handlers you already have */}
      <button aria-label="Edit"   onClick={() => onEdit(row)}   className="icon-btn">{/* edit icon */}</button>
      <button aria-label="Add"    onClick={() => onAdd(row)}    className="icon-btn">{/* plus icon */}</button>
      <button aria-label="Delete" onClick={() => onDelete(row)} className="icon-btn">{/* trash icon */}</button>
      {/* any other actions */}
    </div>

    {/* Responsive fallback: hidden on lg, shown on small */}
    <div className="actions-menu">
      <button aria-label="More" className="icon-btn">{/* ⋮ */}</button>
      <div className="menu">
        <button onClick={() => onEdit(row)}>Edit</button>
        <button onClick={() => onAdd(row)}>Add</button>
        <button onClick={() => onDelete(row)}>Delete</button>
      </div>
    </div>
  </td>

```

> Important: **Do not** leave any leftover wrapper that forces the icons into a new `<tr>`, block `<div>` with `display:block`, or inserted `<br/>`. All actions must sit inline inside the same row (`<tr>`).
