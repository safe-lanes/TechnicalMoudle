Topic: Fleet Spares Bulk Import – Table Creation & Data Storage Design

Context

In Bulk Data Import → Fleet Data Import, when the user selects the option Fleet Spares, an Excel template is used to bulk import Fleet-level spare part master data.

Currently:

There is no clearly defined or enforced storage table for Fleet Spares bulk-imported data

Data persistence behavior is unclear or inconsistent

A dedicated Fleet-level table is required to standardize Fleet Spares data storage.

Requirement Overview

When Fleet Spares is selected in Bulk Data Import:

Imported data must be saved in a new table named fleet_spares

If the fleet_spares table does not exist:

It must be created

While creating the table:

Mandatory system columns (as already defined for all new tables) must be added

The table must include all columns from the Fleet Spares Import Template, mapped correctly
