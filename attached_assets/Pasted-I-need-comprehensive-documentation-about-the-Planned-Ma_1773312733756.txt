I need comprehensive documentation about the Planned Maintenance System (PMS) next due date calculation logic and rules to solve an anti-fraud problem.

PROBLEM CONTEXT:
In our PMS, when a work order is completed, the crew enters the completion date in the work order form. The system then calculates the next due date based on that completion date and the job frequency. This creates a fraud vulnerability:

- Example: A weekly job (7-day frequency) should be done every 7 days
- If crew skips 3 weeks and completes the form on day 28 (end of month)
- System calculates next due date as: day 28 + 7 days = day 35
- This effectively skips 3 weeks of required maintenance
- Crew can manipulate dates to reduce workload

The same issue applies to:
1. Calendar-based jobs (Daily, Weekly, Monthly, Yearly)
2. Running Hours based jobs (equipment runtime)
