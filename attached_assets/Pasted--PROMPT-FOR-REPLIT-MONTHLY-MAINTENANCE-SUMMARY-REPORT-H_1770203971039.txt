DATA CALCULATION LOGIC
─────────────────────────────────────────────────────────

Report Period: User-selected month (e.g., January 2026)

QUERIES NEEDED:

1. Total Planned Jobs:
   COUNT(*) WHERE status = 'Planned' AND MONTH(next_due_date) = [selected_month]

2. Total Completed Jobs:
   COUNT(*) WHERE status = 'Completed' AND MONTH(completion_date) = [selected_month]

3. Total Overdue Jobs:
   COUNT(*) WHERE status = 'Planned' AND next_due_date < CURRENT_DATE

4. Completion Rate:
   (Total Completed / (Total Completed + Total Planned)) * 100

5. On-Time Completion %:
   (COUNT where completed_date <= due_date) / Total Completed * 100

6. Department Breakdown:
   GROUP BY department
   COUNT for each status

7. Priority Breakdown:
   GROUP BY job_priority
   COUNT for each status

8. Frequency Analysis:
   GROUP BY frequency_unit
   COUNT jobs and completion status

9. Man-Hours:
   SUM(manhours) FROM work_completion
   WHERE completion_date IN [selected_month]

10. Critical Equipment:
    COUNT WHERE class_related = 'Yes'
    GROUP BY status
