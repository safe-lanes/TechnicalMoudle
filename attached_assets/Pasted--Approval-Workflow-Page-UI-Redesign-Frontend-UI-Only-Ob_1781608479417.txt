# Approval Workflow Page – UI Redesign (Frontend/UI Only)

## Objective

Redesign the Approval Workflow page UI based on the attached reference screen and existing PMS UI standards.

**Important:**
This task is strictly limited to UI development and layout creation only.

Do not perform any backend development, database changes, API integrations, business logic implementation, workflow processing, validation logic, or save functionality as part of this task.

The objective is only to build the complete UI structure and navigation flow.

---

## Page Location

The Approval Workflow page should be developed at the target location shown in the attached screenshot.

The page layout, styling, spacing, fonts, colors, navigation structure, and overall design should remain consistent with other PMS screens currently available in the application.

The left-side navigation panel should follow the same UI pattern used throughout the PMS module.

## UI Requirements

* Follow existing PMS UI standards and styling.
* Match the layout and design pattern used across other PMS pages.
* Keep the left navigation panel identical to other PMS screens.
* Maintain proper spacing, alignment, and typography.
* Use consistent checkbox styling throughout the page.
* Right-side content should refresh dynamically based on the selected menu item.
* Ensure responsive behavior for desktop and tablet views.
* Create a professional and modern interface suitable for PMS operations.

## Out of Scope

Do not implement:

* Backend logic
* Database operations
* Save functionality
* Approval processing
* Workflow execution
* Validation rules
* API integrations
* Role-based permissions

Build only the UI layout, navigation structure, and checkbox configuration screens.
