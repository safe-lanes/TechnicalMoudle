Raplit Prompt — Copy Vessel (Jobs) Validation Enhancement
Module

PMS → Fleet & Vessel Manager → Copy Vessel → Jobs

🎯 Objective

Enhance the existing Copy Vessel – Jobs functionality by introducing field-level exclusions during replication.

Current functionality correctly copies vessel job configuration from Source Vessel to Target Vessel.

Now implement validation to prevent copying job execution history and scheduling fields.

📌 Change Type

Backend Validation Adjustment

No UI change
No workflow change
No permission change

⚙️ Updated Copy Logic Requirement

When copying jobs from:

Source Vessel → Target Vessel


The system must:

Replicate job configuration data

Replicate mapping references

Replicate interval settings

Exclude operational execution and due tracking fields

🚫 Columns That Must NOT Be Copied

The following fields from the jobs table must be excluded during replication:

last_done_date
next_due_date
last_done_rh
next_due_rh

🔎 Expected Behavior for Excluded Fields

For the Target Vessel:

These fields must be:

Set to NULL
OR

Reinitialized according to standard job initialization logic

They must NOT inherit values from the Source Vessel.

🧠 Rationale

These fields represent:

Job completion history

Next due scheduling

Running hour-based tracking

Copying them would incorrectly transfer maintenance history and due status from one vessel to another.

Each vessel must calculate its own:

Maintenance cycle

Due schedule

RH tracking

Independently.

🧩 Data Integrity Rules

Do not copy job execution history

Do not carry over due calculations

Do not transfer RH-based scheduling state

Maintain mapping integrity (job_code + fleet_equipment_code)

Preserve referential consistency

🧪 Validation Checklist

After copy:

Job structure must replicate correctly

Mapping references must remain intact

Due dates must be empty/reset

RH values must be NULL/default

No incorrect “overdue” status should appear

📌 Scope Limitation

Applies only to:

Copy Vessel → Jobs


No impact on:

Components copy logic

Spares mapping

Job master configuration

Auto Match logic

✅ Expected Outcome

Clean job configuration replication

No transfer of maintenance history

Proper reinitialization of scheduling

Accurate vessel-level maintenance tracking
