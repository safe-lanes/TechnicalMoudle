CRITICAL BUG: LSA/FFA Equipment Detection System Failing for Some Vessels

PROBLEM DESCRIPTION:
The LSA/FFA Equipment detection system is failing to identify Life-Saving Appliances (LSA) and Fire-Fighting Appliances (FFA) for certain vessels, even though these vessels have components with the correct "Equipment / System Department" field set to "LSA" or "FFA".

EVIDENCE OF THE BUG:

VESSEL ALEJANDRO (Broken - Not Detecting LSA/FFA):
1. In Components Module:
   - Component Code: 501.001.01
   - Component Name: LIFEBOAT, W/EQUIPMENT
   - Equipment / System Department: LSA
   - This component EXISTS and is properly tagged as LSA equipment

2. In LSA/FFA Equipment Master List Report:
   - Shows: "Complete Inventory - 0 components (LSA: 0, FFA: 0)"
   - Vessel: Alejandro
   - Report Period: All Time
   - Total LSA: 0
   - Total FFA: 0
   - Result: "No LSA/FFA components found"
   
   THIS IS WRONG - Vessel Alejandro HAS LSA equipment but the system is not detecting it!

VESSEL 3 (Working Correctly - Detecting LSA/FFA):
1. In Components Module:
   - Component Code: 501.002
   - Component Name: Covered Lifeboats
   - Equipment / System Department: LSA
   - This component exists and is tagged as LSA

2. In LSA/FFA Equipment Master List Report:
   - Shows: "Complete Inventory - 21 components (LSA: 11, FFA: 10)"
   - Vessel: Vessel 3
   - Report Period: All Time
   - Total LSA: 11
   - Total FFA: 10
   - Result: Table displays all 21 LSA/FFA components correctly
   - Components include: Covered Lifeboats, Liferaft, No.1 Liferaft, No.2 Liferaft, Hand Flare, Life-jacket, Parachute Signal Rocket Red, Lifebuoy, Line-throwing appliance, Immersion Suit, No.1 Lifebuoy, Wheeled CO2 Fire Extinguisher, Portable Foam Fire Extinguisher, etc.
   
   THIS IS CORRECT - Vessel 3's LSA/FFA equipment is properly detected and listed.

ROOT CAUSE ANALYSIS REQUIRED:
═══════════════════════════════════════════════════════════

The LSA/FFA detection system is inconsistent across vessels. Some possible causes to investigate:

HYPOTHESIS 1: Vessel Association Issue
- Components might not be properly linked to the vessel in the database
- Check if component.vessel_id is correctly set for Vessel Alejandro's LSA equipment
- Verify foreign key relationships between components and vessels tables

HYPOTHESIS 2: Field Mapping Issue
- The "Equipment / System Department" field might have different database column names or values
- Check if the field is stored as:
  - "LSA" vs "lsa" (case sensitivity)
  - "LSA" vs "Life-Saving Appliances"
  - Different enum values or text variations
- Verify the exact database value for Vessel Alejandro's component vs Vessel 3's components

HYPOTHESIS 3: Query Filtering Logic Error
- The LSA/FFA report query might have additional WHERE conditions that exclude Vessel Alejandro
- Check if there are filters based on:
  - Component status (active/inactive)
  - Installation date
  - Criticality flags
  - Parent component relationships
  - Component category

HYPOTHESIS 4: Data Migration or Import Issue
- Vessel Alejandro's data might have been imported differently than Vessel 3
- Check if equipment_system_department field is NULL for Alejandro despite UI showing "LSA"
- Verify if the data is in a different table or schema for some vessels

HYPOTHESIS 5: Equipment Type Classification
- The system might use multiple fields to identify LSA/FFA equipment:
  - Equipment Type field
  - Component Category field
  - Equipment / System Department field
- All three fields might need to be set correctly, and Alejandro might be missing one
