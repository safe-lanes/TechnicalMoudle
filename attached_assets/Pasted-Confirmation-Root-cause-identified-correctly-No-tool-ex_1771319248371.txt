Implementation Requirements
1. Tool Definition Specifications
javascript
{
  name: "get_fleet_overview",
  description: "Get complete fleet information including vessel count, list of all vessels with their IDs, names, and status. Use this for questions like 'how many vessels', 'list all vessels', 'show fleet', 'which vessels are active'.",
  parameters: {
    type: "object",
    properties: {},
    required: []
  }
}
Important: No parameters needed since this is fleet-wide data.

2. Tool Handler Implementation
In executeToolCall function, add:

javascript
case 'get_fleet_overview':
  const vessels = await storage.getVessels();
  return {
    totalVessels: vessels.length,
    vessels: vessels.map(v => ({
      id: v.id,
      name: v.name,
      status: v.status || 'Active'
    }))
  };
