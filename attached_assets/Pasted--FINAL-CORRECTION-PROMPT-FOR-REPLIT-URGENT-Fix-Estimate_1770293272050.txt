URGENT: Fix "Estimated" Data Calculation in Equipment Utilization Report
Problem
The report now has 3 data categories (Actual, Estimated, No Data), but "Estimated" components (88 total) still use Period Hrs = Current Hrs, producing impossible utilization percentages like 558% and 2084%.

Root Cause
For components without historical data, the code is doing:

javascript
periodHours = component.running_hours;  // ❌ Uses total cumulative hours
This treats total cumulative hours (e.g., 4020 since installation) as if it was accumulated in the 30-day period, which is impossible.

Required Fix
Cap Estimated Period Hours at Realistic Maximum:
javascript
// For "Estimated" components (no historical data):
if (!startReading && component.running_hours > 0) {
  const maxPossibleHours = daysInPeriod * 24; // e.g., 30 × 24 = 720 hours max
  
  if (component.running_hours <= maxPossibleHours) {
    // Current hours fit within period - use as-is
    periodHours = component.running_hours;
    dataSource = 'Estimated';
  } else {
    // Current hours exceed period max - cap at 80% utilization
    // (reasonable estimate for continuously running equipment)
    periodHours = Math.floor(maxPossibleHours * 0.80);
    dataSource = 'Estimated (capped)';
  }
}
