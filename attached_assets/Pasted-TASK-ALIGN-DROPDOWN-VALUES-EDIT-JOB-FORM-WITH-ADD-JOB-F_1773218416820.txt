TASK: ALIGN DROPDOWN VALUES – EDIT JOB FORM WITH ADD JOB FORM

Objective:

Ensure that all dropdown fields in the **Edit Job Form – Function Section** contain the **same values as the corresponding dropdowns in the Add Job Form**.

--------------------------------------------------

1. Current Issue Analysis

Perform a detailed analysis of the dropdown fields in:

• Add Job Form – Function Section  
• Edit Job Form – Function Section  

Verify whether the dropdown values are identical in both forms.

--------------------------------------------------

2. Comparison Checklist

Identify and compare:

• Task Type dropdown values  
• Maintenance Type dropdown values  
• Frequency Unit dropdown values  
• Any other dropdowns present in the Function section

Check whether:

• Values are missing in Edit Job form  
• Values differ between the two forms  
• Data source for dropdowns is different

--------------------------------------------------

3. Data Source Verification

Identify how the dropdown values are currently populated:

• Static values in frontend  
• API response  
• Database lookup tables  
• Configuration lists

Confirm whether the **Add Job Form and Edit Job Form use the same data source or different sources**.

--------------------------------------------------

4. Root Cause Identification

Determine why the dropdown values differ between the two forms, such as:

• Separate dropdown value lists used in each form  
• Hardcoded values in one form  
• Different API endpoints used  
• Missing synchronization between Add and Edit forms

--------------------------------------------------

5. Implementation Plan

To correct the issue:

• Ensure that both **Add Job Form and Edit Job Form use the same data source** for dropdown values.
• Standardize the dropdown population logic so both forms fetch values from the same list/API/configuration.
• Remove any duplicate or hardcoded lists used only in the Edit Job Form.

--------------------------------------------------

6. Validation

After implementation verify:

Test 1  
Open **Add Job Form → Function Section** and note dropdown values.

Test 2  
Open **Edit Job Form → Function Section** and confirm that all dropdowns contain the same values.

--------------------------------------------------

Expected Result

• All dropdowns in Edit Job Form contain the same values as Add Job Form  
• Both forms use a single standardized data source for dropdown values
