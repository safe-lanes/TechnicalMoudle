STEP 1 — Calculation Service (Backend First)
Create server/modules/noon-report/services/calculationEngine.ts.

This service must be called automatically every time a noon report is submitted (hook into the submission controller, after the record is saved). It must compute and store all of the following:

ROB Calculations:

Update nr_fuel_rob table: for each fuel type, newROB = previousROB − todayConsumption

If any fuel type ROB would go negative, do NOT block submission — instead flag it in nr_alerts with severity critical and set ROB to 0

Rolling Averages:

3-day rolling average consumption (sum of last 3 submitted reports ÷ 3) per fuel type

7-day rolling average consumption (sum of last 7 submitted reports ÷ 7) per fuel type

Store both in nr_fuel_rob as avg3Day and avg7Day columns (add these columns to schema if not present)

Endurance:

enduranceDays = totalROB ÷ 7dayAvgDailyConsumption

enduranceNM = totalROB ÷ (7dayAvgConsumption ÷ 7dayAvgSpeed) — use average speed from last 7 reports

Store both in nr_fuel_rob as enduranceDays and enduranceNM

CII / Emissions:

Running year-to-date co2Total accumulation per vessel

AER (Annual Efficiency Ratio) = ytdCO2Grams ÷ (vesselDWT × ytdDistanceNM)

CII band: compare AER against IMO reference line to assign A / B / C / D / E

Store in a new nr_cii_tracking table: vesselId, year, ytdCO2MT, ytdDistanceNM, aer, ciiRating (upsert on each submission)

EEOI:

EEOI = (fuelConsumed MT × co2Factor) ÷ (cargoMT × distanceNM) — per voyage leg

Store in nr_voyage_legs

Create server/modules/noon-report/utils/fuelConversionFactors.ts with:

IMO CO₂ factors per fuel type (HFO: 3.114, MGO/LSMGO: 3.206, VLSFO: 3.151, LPG: 3.030)

CII reference line coefficients (a and c values per vessel type — use bulk carrier defaults, make vessel type configurable later)

Default safety margin: 15% (configurable)

Alert thresholds: consumption spike >15% = warning, >25% = critical; ROB endurance <10 days = warning, <5 days = critical
