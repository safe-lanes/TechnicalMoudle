Drawback 5 — Bulk import double-counting risk
If a user's Excel file contains 4,500 hrs in the Running Hours column, and the component already has meter_replaced_last_rh = 4,000 hrs from a prior meter replacement, the import writes current_cumulative_rh = 4,500. The grid then displays 4,500 + 4,000 = 8,500 hrs — which is double-counted and wrong.
