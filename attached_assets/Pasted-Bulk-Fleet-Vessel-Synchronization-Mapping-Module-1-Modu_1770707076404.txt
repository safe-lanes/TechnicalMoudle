Bulk Fleet ↔ Vessel Synchronization Mapping Module
1. Module Purpose

This module automatically establishes mapping between:

• Fleet Master Components
• Vessel Installed Components

Using:

👉 Fleet Equipment Code as the universal reference key
👉 Fully automated bulk matching
👉 Preview confirmation safeguard
👉 Transaction-based database insertion

2. Functional Scope
The Module WILL:

✔ Display Fleet component hierarchy
✔ Display Vessel component hierarchy
✔ Perform automatic bulk matching
✔ Show preview before saving
✔ Store mapping in backend
✔ Prevent duplicate linkage

The Module WILL NOT:

❌ Allow manual selection
❌ Allow manual mapping
❌ Allow partial component selection

5. Matching Algorithm (Production Logic)
Step 1 – Load Fleet Components

Retrieve:

fleet_components_uuid

fleet_equipment_code

Step 2 – Load Vessel Components

Retrieve:

component_code_uuid

fleet_equipment_code

vessel_id

Step 3 – Perform Matching
Core Rule
IF vessel.fleet_equipment_code == fleet.fleet_equipment_code
THEN create mapping candidate

Step 4 – Exclusion Rules

Skip if:

• Vessel component already mapped
• Fleet code is null
• Fleet component does not exist

8. Database Design
Table Name
fleet_vessel_mapping

Final Column Structure
Column	Type	Description
fleet_vessel_mapping_uuid	UUID (PK)	Unique mapping ID
fleet_components_uuid	UUID	Fleet component reference
component_code_uuid	UUID	Vessel component reference
fleet_equipment_code	VARCHAR	Matching reference
vessel_id	VARCHAR / UUID	Vessel reference
Database Constraints
Primary Key
fleet_vessel_mapping_uuid

Foreign Keys
fleet_components_uuid → fleet_components
component_code_uuid → vessel_components

Unique Constraint
(component_code_uuid, vessel_id)


👉 Prevents multi mapping inside same vessel.

Recommended Indexes
INDEX fleet_equipment_code
INDEX vessel_id
INDEX component_code_uuid
