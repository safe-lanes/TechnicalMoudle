Phase 2 plan is approved with the following clarifications. Apply these before writing any code:

Clarification 1 — CII Gauge active band indicator:
The colour-banded horizontal bar must clearly show which band is currently active. The active band (e.g. "B") must be visually highlighted — use a bold border, slightly raised height, or a pointer arrow above it. The CII letter must also be displayed large and bold in a separate text element next to or above the gauge bar. Do not just render a static 5-colour bar with no active state indicator.

Clarification 2 — minBunkerToNextPort data source:
To calculate minimum bunker to next port, use distanceToGo from the most recently submitted noon report for this vessel. Formula: minBunkerToNextPort = distanceToGo ÷ (avg7DayNMperMT) where avg7DayNMperMT = avgDistanceSailed7Day ÷ avg7DayTotalConsumption. If distanceToGo is null or 0 in the last report, return null for this field and show "—" in the UI card.

Clarification 3 — Vessel DWT:
Before writing the CII calculation, confirm the exact field name for DWT in the existing vessels table by checking existingDataAdapter.ts or the existing schema. If DWT is not available in the existing data, add a vesselDwt field to the nr_fuel_rob or a new nr_vessel_config table that can be manually set per vessel from the Admin role. Do not silently default DWT to 0 — if DWT is missing, the AER calculation must return null and the CII gauge must show "N/A" with a tooltip: "Vessel DWT not configured. Contact Admin."

Clarification 4 — Total Endurance calculation:
enduranceDays stored per fuel type row is fine for per-fuel tracking. But the Bunker Planning Card must display total combined endurance = sum of all fuel type ROBs ÷ total 7-day average daily consumption across all fuel types. Compute and return this as a separate totalEnduranceDays and totalEnduranceNM field in the dashboard API response.

Clarification 5 — Empty state handling:
Every UI component on the Fuel Dashboard must handle the case where no noon reports exist yet for this vessel:

ROB cards: show "No data" with a gray badge

Consumption trend chart: show an empty state message — "Submit your first noon report to see fuel trends"

CII gauge: show "N/A"

Bunker Planning Card: show "—" for all values

Scatter chart: show "No data yet"
Never show NaN, undefined, or blank white space.

All other aspects of the plan are approved as written. Proceed with Phase 2.
