Popup purpose
Inside the popup, the user should be able to define company standard grace rules.

The grace configuration should support 3 grace methods, but only one can be selected at a time.

Grace method options
Use radio buttons, not checkboxes, because only one option should be active.

The 3 grace method options are:

Fixed Days

Month End

Specific Date of Next Month

Only one of these can be selected at a time.

Meaning of each grace option
1. Fixed Days
User enters a numeric number of days.
Example:

If due date is 10 April

Fixed Days = 7

Grace valid until 17 April

2. Month End
Grace remains valid until the end of the same month in which the WO is due.

Example:

If due date is 10 April

Grace valid until 30 April

3. Specific Date of Next Month
User enters a day number of the next month.

Example:

If user enters 5

Then grace is allowed until the 5th of next month

If WO due date is 28 April, grace remains valid until 5 May

Please validate day input properly so only valid day-of-month values are accepted.

Scope logic
In addition to selecting the grace method, the user should also select the scope of where this rule applies.

This should also use radio button selection, because only one scope should be active at a time.

Scope options
Apply to all Work Orders

Apply only to Work Orders due in last week of the month

Only one of these scope options can be selected.

Important special requirement
If the user selects:

Apply only to Work Orders due in last week of the month

then the system must also provide a way to define what happens for all other WOs that are not due in the last week of the month.

This is important because otherwise the rule becomes incomplete.

Required behavior
When the scope selected is:

Apply only to Work Orders due in last week of the month

then show an additional input section to define the grace value for the remaining WOs.

This additional field should only appear when that scope is selected.

Additional field behavior
This field is for:

WOs not due in the last week of the month

We can keep this fallback simple for now:

provide one extra text box for a grace period value for remaining WOs

This is meant to complete the rule so both groups are covered:

WOs due in last week of month

all other WOs

This fallback value should only appear when:
