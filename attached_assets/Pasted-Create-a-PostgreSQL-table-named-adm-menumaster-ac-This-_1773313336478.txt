| Column          | Type        | Notes                         |

• `muid` must be **UNIQUE**
• `parent_menu` must reference **muid** in the same table (self-reference)
• `created_by_uuid` and `updated_by_uuid` must allow **NULL**
• `created_at` default **NOW()**
• `updated_at` default **NOW()**
• `is_active` default **true**
• `is_deleted` default **false**
