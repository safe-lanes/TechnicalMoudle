Prompt for Replit – Fix “Spares by Location” Visibility Issue (Single Location Assignment)

Issue Description

In a newly created vessel:

The Location master is not preloaded.

In the Spares module, both Location A and Location B fields are initially empty.

When:

Only Location A is created and assigned to a spare, and ROB is updated →
The location is correctly stored in the location table.

However, the spare is not visible in the “Spares By Location” tab.

If Location B is also entered for the same spare →
Then it becomes visible in the “Spares By Location” tab.

Expected Correct Behavior

If any one location (Location A or Location B) is assigned to a spare, that spare must be visible in the Spares By Location tab.

It must not require both locations to be filled.

Tasks to Perform
1. Investigate the Root Cause

Check the query logic used in the Spares By Location tab:

Verify whether the filtering condition is:

Incorrectly using AND between location_a and location_b

Instead of OR

Example of possible incorrect logic:

WHERE location_a IS NOT NULL AND location_b IS NOT NULL

Correct logic should be:

WHERE location_a IS NOT NULL OR location_b IS NOT NULL

Also verify:

If JOIN condition with location table is excluding records when one location is NULL.

If frontend filtering logic is suppressing partial-location records.

If vessel-based filtering is blocking newly created location records.

2. Fix the Query Logic

Update the backend logic so that:

A spare is displayed if:

location_a is filled
OR

location_b is filled

Even if only one of them is assigned.

Ensure:

No dependency exists requiring both fields.

No hardcoded condition blocks single-location records.

3. Validation Logic Update

Ensure:

System allows assigning only one location.

No forced validation requiring both Location A and Location B.

Location assignment is independent.

4. New Vessel Handling

For new vessels:

Ensure location data loads properly.

Confirm location master table is vessel-linked correctly.

Ensure the Spares By Location tab fetches vessel-specific location mapping properly.

Expected Result After Fix

If only Location A is assigned → Spare must appear in Spares By Location.

If only Location B is assigned → Spare must appear.

If both assigned → Spare must appear.

Visibility must not depend on both fields being populated.

Important

Test with:

New vessel

Existing vessel

Single location assignment

Dual location assignment

Ensure no regression in location filtering logic.
