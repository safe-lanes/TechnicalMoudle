Raplit Analysis Prompt – Reports → Maintenance & Work Orders → Standard Excel Export Format
Context
In the Reports module, under:
Reports → Maintenance & Work Orders
multiple Excel-based reports are generated (Due Jobs, Overdue Jobs, Completed Jobs, etc.).
A single standard Excel template has already been defined and attached for this section.
Authoritative Requirement (Very Strict)
1. Standard Excel Column Format (Non-Negotiable)
ALL Maintenance & Work Orders Excel reports must use:
The same attached Excel file column format except Man-Hours Planned vs Actual and Crew Workload Distribution Report.
Column headers:
Must NOT be changed
Must NOT be added
Must NOT be removed
The column structure is common and fixed for all reports in this section
✔ Only the following are allowed to vary per report:
Section header / report title
Summary data (counts, totals, etc.)
Filtered dataset (Due / Overdue / Completed, etc.)
2. Report-Specific Formatting Rules (Excel Highlighting)
The Excel output must apply row-level colour highlighting based on job status and criticality.
Colour Coding Rules (Mandatory)
Job Condition	Highlight Colour
Due Jobs	Light Orange
Due Jobs – Critical Equipment	Dark Orange
Overdue Jobs	Light Red
Overdue Jobs – Critical Equipment	Dark Red
Completed Jobs	Light Green
Completed Jobs – Critical Equipment	Dark Green
Unplanned Jobs	Yellow
Postponed Jobs	Sky Blue
3. Scope of Analysis
Analyse only:
Excel export logic for:
Reports → Maintenance & Work Orders except Man-Hours Planned vs Actual and Crew Workload Distribution Report.
How:
Column headers are defined
Data rows are populated
Conditional formatting is applied
Whether:
A single reusable Excel template is used
Or each report generates its own structure
4. Key Analysis Questions
Excel Template Consistency
Is the same column schema used across all Maintenance & Work Order reports? except Man-Hours Planned vs Actual and Crew Workload Distribution Report.?
Are any reports currently adding/removing columns?
Column Header Control
Where are column headers defined?
Are headers dynamically generated or hardcoded?
Conditional Formatting Logic
How is job status identified in export logic?
How is critical equipment flagged?
Is colour formatting applied row-wise or cell-wise?
Report-Specific Customisation
How are section headers and summaries injected?
Can these be changed without affecting column structure?
🚫 Explicit Constraints
This analysis must NOT:
❌ Change Excel column headers
❌ Add new columns
❌ Remove existing columns
❌ Modify business logic of reports
❌ Affect data filtering rules
❌ Impact non-Maintenance reports
This is analysis and planning only.

Confirmation whether a single standard Excel structure is currently enforced
