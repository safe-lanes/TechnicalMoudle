Problem 1 — Previous Reading is showing wrong data:

Currently it shows 0.00. This field must show the running hours at which this specific job was last completed. This means you need to query the most recently completed work order for the same component and same job code, and take the Current Reading value that was entered in B3 at the time of that completion. That is the "previous reading" for this job. It is NOT the component's current cumulative running hours. It is the RH snapshot recorded when this job was last done.

Problem 2 — Component Actual RH is showing 0 hrs:

This field must show the component's present running hours from the Running Hours module. The API endpoint for this is GET /technical/api/running-hours/current?machineryId={componentId}. Currently it is fetching 0 hrs which means either the componentId being passed is wrong, the API is returning zero, or there is an error being silently swallowed. Check what componentId is being sent in the request, verify it matches the component attached to this work order, check the API response, and fix it so the correct live value loads when the page opens.

Problem 3 — Validation range upper limit is wrong:

From the screenshot, the validation error says "Valid range: 1500 to 87444 hours". The upper limit of 87444 hours is clearly a bug. A machinery component running 87444 hours continuously would be over 9 years of 24/7 operation which is unrealistic. The upper limit must be calculated as Component Actual RH from the Running Hours module, not some hardcoded or incorrectly derived large number. The valid range for Current Reading must be: minimum is Previous Reading, maximum is Component Actual RH. Fix this validation to use the correct ceiling.

Summary of what each field should show:

Previous Reading = RH value entered in B3 when this job was last completed (from most recent completed work order for same component + job code)

Component Actual RH = Current running hours of the component from the Running Hours module (live fetch)

Current Reading = User enters this manually, must be between Previous Reading and Component Actual RH

Valid range shown to user = Previous Reading to Component Actual RH
