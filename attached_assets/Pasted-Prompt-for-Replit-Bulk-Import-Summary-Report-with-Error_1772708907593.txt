Prompt for Replit – Bulk Import Summary Report with Error Details and Excel Export

Objective

After completing any Bulk Import process (Components, Jobs, Spares, Maker List, etc.), the system must generate a detailed Import Summary Report showing the status of each record processed.

1. Import Summary Popup

Once the import process finishes:

A summary popup/modal window must automatically appear.

The popup should display a row-by-row summary of the imported data.

The table should contain:

Row Number

Main Columns from the Import File

Import Status

Error / Validation Message (if any)

Example table structure:

Row No | Component Code | Component Name | Status   | Error Message
--------------------------------------------------------------------
1      | 1234567        | Main Engine    | Success  | -
2      | 1234568        | Aux Engine     | Failed   | Invalid Department
3      | 1234569        | Generator      | Success  | -
2. Status Indicators

Each row must clearly show one of the following statuses:

Success → Record imported correctly.

Failed → Record not imported due to validation or data issues.

If failed:

The exact validation error message must be displayed.

Example errors:

Invalid Equipment/System Department

Maker not found in Maker_List

Duplicate Component Code

Missing mandatory field

3. Error Transparency

The summary must help the user quickly identify the issue by:

Showing exact reason for failure

Highlighting failed rows (optional UI enhancement)

This helps the user correct the file and re-import.

4. Excel Export Option

The popup must include a button:

Export Summary to Excel

When clicked:

The system should download an Excel file containing the same summary table.

Excel sheet should contain columns such as:

Row Number
Primary Identifier (Component Code / Job Code / Part Code etc.)
Main Columns
Status
Error Message
5. Import Summary Statistics (Optional but Recommended)

At the top of the popup, display:

Total Records Processed

Successfully Imported

Failed Records

Example:

Total Records: 120
Successful Imports: 110
Failed Imports: 10
6. Backend Requirements

The import process must:

Capture validation errors row by row

Store the result temporarily

Send the result to the UI after import completion

Ensure:

Failed rows do not stop the entire import

Only invalid rows are skipped.

Expected Final Behavior

User uploads import file.

System processes all rows.

Import completes.

Summary popup appears automatically.

User sees:

Success records

Failed records with error reasons.

User can export the report to Excel.
