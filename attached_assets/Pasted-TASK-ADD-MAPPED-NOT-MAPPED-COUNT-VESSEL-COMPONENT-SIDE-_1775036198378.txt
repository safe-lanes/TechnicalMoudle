TASK: ADD MAPPED / NOT MAPPED COUNT – VESSEL COMPONENT SIDE (FLEET VESSEL MAPPING PAGE)

Objective:

Display **Mapped and Not Mapped count** in the **Vessel Component side**, similar to the Fleet side, with correct filtering logic.

--------------------------------------------------

1. Current Behavior

• Fleet side shows:
  - Mapped count  
  - Not Mapped count  

• Vessel Component side currently does NOT show this count  

--------------------------------------------------

2. Required Enhancement

• Add **Mapped / Not Mapped count display** in the **Vessel Component section**  

--------------------------------------------------

3. Mapping Logic (Important)

Current system behavior:

• Mapping is performed only for components where:
  
  is_parent = No  

--------------------------------------------------

4. Count Calculation Rule

Counts must be calculated ONLY for:

• Components where:

  is_parent = No  

--------------------------------------------------

5. Count Definitions

A. Mapped Count

• Number of components (is_parent = No)  
• Which are already mapped to Fleet  

--------------------------------------------------

B. Not Mapped Count

• Number of components (is_parent = No)  
• Which are NOT mapped to Fleet  

--------------------------------------------------

6. Data Filtering Logic

Apply condition:

WHERE is_parent = 'No'

Only these records should be considered for:

• Total count  
• Mapped count  
• Not mapped count  

--------------------------------------------------

7. UI Requirement

• Display counts in Vessel Component section similar to Fleet side:

Example:

Mapped: 120  
Not Mapped: 45  

--------------------------------------------------

8. Validation

• Ensure counts match actual mapping data  
• Ensure parent components (is_parent = Yes) are NOT included  
• Ensure consistency between mapping logic and count logic  

--------------------------------------------------

Expected Result:

• Vessel Component section shows accurate mapped and not mapped counts  
• Counts reflect only non-parent components  
• UI consistency maintained with Fleet side
