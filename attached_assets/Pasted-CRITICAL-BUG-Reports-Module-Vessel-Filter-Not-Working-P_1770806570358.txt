CRITICAL BUG: Reports Module - Vessel Filter Not Working
Problem Statement
The reports in the PMS Reports module are not respecting the vessel selection from the dropdown filter. Reports are generating data irrespective of which vessel is selected, showing incorrect vessel data.

Current Behavior (Bug)
When selecting "Vessel 1" from the vessel dropdown on /pms/reports

Clicking on any report category (e.g., "Maintenance Planner")

The report displays data for "Vessel 4" instead of "Vessel 1"

The report header shows "Planning view for Vessel 4" with 156 jobs

All report data (jobs, spares, stores, etc.) appears to be from a different vessel than selected

Expected Behavior
When a specific vessel is selected (e.g., "Vessel 1"):

All reports should display ONLY data for that specific vessel

Report headers should show "Planning view for Vessel 1" (or respective vessel name)

All counts, statistics, and data tables should be filtered by the selected vessel

The vessel filter should persist when navigating between different report categories

When "All Vessels" is selected:

Reports should compile and aggregate data from ALL vessels in the system

Report headers should indicate "All Vessels" or "Fleet-wide" view

Summary statistics should show combined totals

Data tables should include vessel identification column to distinguish which data belongs to which vessel

Affected Report Categories (All 7 categories)
Maintenance Planner - Currently showing Vessel 4 data regardless of filter

Maintenance & Work Orders (10 reports) - Need vessel-specific filtering

Running Hours & Condition (2 reports) - Need vessel-specific filtering

Inventory - Spares (3 reports) - Need vessel-specific filtering

Inventory - Stores/Lubes/Chemicals (5 reports) - Need vessel-specific filtering

IHM (Inventory of Hazardous Materials) (1 report) - Need vessel-specific filtering

Modify PMS (Change Requests) (1 report) - Need vessel-specific filtering
