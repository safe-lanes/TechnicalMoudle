Prompt for Replit

Objective:
Analyze and optimize a PostgreSQL migration script that adds Stores sub-menu items and seeds role-menu access. The script must follow best practices, use default values for permissions, and ensure data integrity and idempotency.

📌 Context

I am working on a PostgreSQL-based application that manages menus and role-based access control. The migration performs the following tasks:

Inserts submenu items under the pms-stores parent menu.
Seeds the adm_role_menu_access table for all active roles.
Uses default permission values instead of explicitly assigning them, as permissions are managed in a separate table.
📂 Database Tables Involved
adm_menumaster_ac – Stores application menus.
admn_role_master – Stores role information.
adm_role_menu_access – Stores role-based access permissions.
📜 Migration Script to Analyze
-- Migration: Add Stores sub-menu items (Stores, Lubes, Chemicals, Others)
-- and seed role-menu-access for all active roles using default permissions

BEGIN;

INSERT INTO adm_menumaster_ac (
    id, muid, name, display_name, route, parent_menu,
    is_active, sort_order, created_at, updated_at, is_deleted, is_sync
)
VALUES
  (27, gen_random_uuid(), 'pms-stores-stores',    'Stores',    '/stores?tab=stores',
   (SELECT muid FROM adm_menumaster_ac WHERE name = 'pms-stores' LIMIT 1),
   true, 101, NOW(), NOW(), false, false),

  (28, gen_random_uuid(), 'pms-stores-lubes',     'Lubes',     '/stores?tab=lubes',
   (SELECT muid FROM adm_menumaster_ac WHERE name = 'pms-stores' LIMIT 1),
   true, 102, NOW(), NOW(), false, false),

  (29, gen_random_uuid(), 'pms-stores-chemicals', 'Chemicals', '/stores?tab=chemicals',
   (SELECT muid FROM adm_menumaster_ac WHERE name = 'pms-stores' LIMIT 1),
   true, 103, NOW(), NOW(), false, false),

  (30, gen_random_uuid(), 'pms-stores-others',    'Others',    '/stores?tab=others',
   (SELECT muid FROM adm_menumaster_ac WHERE name = 'pms-stores' LIMIT 1),
   true, 104, NOW(), NOW(), false, false)
ON CONFLICT (id) DO NOTHING;

-- Seed role-menu access using default values
INSERT INTO adm_role_menu_access (
    role_ruid,
    menu_muid
)
SELECT
    r.ruid,
    m.muid
FROM admn_role_master r
CROSS JOIN adm_menumaster_ac m
WHERE r.is_active = true
  AND COALESCE(r.is_deleted, false) = false
  AND m.name IN (
      'pms-stores-stores',
      'pms-stores-lubes',
      'pms-stores-chemicals',
      'pms-stores-others'
  )
ON CONFLICT (role_ruid, menu_muid) DO NOTHING;

COMMIT;
