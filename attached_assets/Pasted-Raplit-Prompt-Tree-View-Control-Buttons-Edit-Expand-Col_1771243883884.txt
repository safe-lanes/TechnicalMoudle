Raplit Prompt — Tree View Control Buttons (Edit / Expand / Collapse)
Module

PMS → Fleet & Vessel Manager → Component Structure Tree View

🎯 Objective

In the highlighted Tree View section, add three control buttons:

[ Edit ]   [ Expand ]   [ Collapse ]


These buttons must control only the Tree View display behavior.

No database structural changes.
No impact on table data.
Display-order control only.

🧩 Functional Requirements
1️⃣ Edit Button — Manual Tree Reordering
Purpose

Allow users to reorganize component hierarchy using drag-and-drop in the Tree View.

Behavior

When user clicks Edit:

Tree View enters drag-and-drop mode

User can:

Move component up/down within same parent

Change parent by dragging component under another component

Visual drop indicator must be shown

Show Save and Cancel options

Important Rule

⚠ This feature:

Does NOT change component master data

Does NOT modify table records

Only changes display order

Must store new display order in:

display_sequence / sort_order field

Validation

Cannot drag root under child

Cannot create circular hierarchy

Cannot move locked/system components (if applicable)

Save Behavior

On Save:

Persist updated display order

Refresh tree view

Show success message:

Tree structure updated successfully.


On Cancel:

Revert to previous order

2️⃣ Expand Button — Expand All Children
Behavior

When user:

Selects a component

Clicks Expand

System must:

Expand that component

Expand ALL nested child components recursively

Keep other branches unchanged

If no component selected:

Show message:

Please select a component to expand.

3️⃣ Collapse Button — Collapse Tree
Behavior

When user clicks Collapse:

Collapse entire Tree View

Only show root level components

Reset expanded states

No selection required.

🎨 UI Requirements

Buttons must:

Be placed above or within the Tree View header section

Follow Alpha UI Pattern

Same styling hierarchy as existing action buttons

Proper spacing and alignment

Icons recommended:

Edit → pencil icon

Expand → expand-tree icon

Collapse → collapse-tree icon

⚙️ Technical Constraints

No change in component table schema

No modification of component metadata

Only update display sequence logic

Maintain performance for large trees

Must support deep hierarchy

📌 Scope Limitation

Applies only to:

Component Structure Tree View


No impact on:

Jobs Mapping

Spares Mapping

Fleet Master

Auto Match screens

✅ Expected Outcome

User-friendly manual tree organization

Controlled expand behavior

Quick collapse functionality

Clean, structured UI

No backend structural impact
