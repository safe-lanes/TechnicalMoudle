TASK: HANDLE RH VALIDATION WHEN "METER REPLACED" IS ENABLED

Objective:

Define and implement correct validation logic for **Running Hours (RH)** when **Meter Replaced is selected**, allowing new readings to be lower than previous values.

--------------------------------------------------

1. Current Issue

• System may restrict RH entry to be greater than previous value  
• This validation is incorrect when **Meter is replaced**  

--------------------------------------------------

2. Required Logic

A. When "Meter Replaced" = NOT Selected

• Standard validation applies:
  - New RH must be **greater than or equal to previous RH**  
  - Prevent decreasing values  

--------------------------------------------------

B. When "Meter Replaced" = Selected

• Allow new RH to be **less than previous RH**  

Reason:

• New meter starts from:
  - 0 OR  
  - Any initial reading (calibrated value)  

--------------------------------------------------

3. Functional Behavior

When Meter Replaced is checked:

• Treat entered RH as **new meter base value**  
• Do NOT compare with previous RH for validation  

--------------------------------------------------

4. Data Handling

On meter replacement:

Capture:

• Previous RH (Old Meter Reading)  
• New RH (New Meter Reading)  
• Replacement Date  
• Component ID  
• User ID  

--------------------------------------------------

5. Storage Requirement

• Store old RH in:
  - RH History / Audit table  

• Mark event as:
  - "Meter Replaced"  

--------------------------------------------------

6. Cumulative RH Logic

Maintain:

• Total Running Hours =  
  Previous cumulative RH + New meter incremental usage  

--------------------------------------------------

7. Validation Summary

Condition | Validation Rule  
----------|----------------  
Meter Replaced = No | New RH ≥ Previous RH  
Meter Replaced = Yes | New RH can be ANY value  

--------------------------------------------------

8. UI Behavior

• When checkbox is selected:
  - Show helper text: "New meter reading can be less than previous value"  
• Optional: Highlight field to indicate special condition  

--------------------------------------------------

Expected Result:

• System allows lower RH input when meter is replaced  
• No validation errors in such cases  
• Data integrity maintained with proper history tracking
