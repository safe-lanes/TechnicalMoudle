🔍 Analysis Requirements

First, analyse and document:

How component bulk upload is currently handled

Where component data is:

Parsed

Validated

Inserted

Post-processed

🧱 Refactor Planning Requirements

Prepare a clear phased plan that explains:

Phase 1 — Structural Separation

How to introduce a module folder for components without breaking existing flows

How to move DB-query logic into a repository layer

How to isolate business rules into a service layer

How controllers will orchestrate requests

Phase 2 — Bulk Upload Alignment

How bulk upload logic will:

Call the service layer

Reuse repository methods

Avoid direct DB access

How post-upload effects (if any) will be handled consistently

Phase 3 — REST Exposure

How component fetch APIs will follow RESTful patterns

How routes will map cleanly to controllers

How UUIDs / identifiers are preserved from current logic

Phase 4 — Frontend Integration

How frontend component screens will:

Stop calling legacy APIs

Use a module-specific API file

Consume only RESTful endpoints

How this change remains backward-compatible initially
