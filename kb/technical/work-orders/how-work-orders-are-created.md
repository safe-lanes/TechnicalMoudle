# How work orders are created — the three ways to create a work order
Applies to: Both
Who can do it (role): Depends on the way — (1) planned: nobody, the ship system creates them; office 'Generate Now': Sail Admin only [code: server/modules/work-orders/services/workOrderGenerationGate.ts:44,141-147, replit_dev cf5241ad6]; (2) per-job 'Generate WO': no role check [code: server/modules/jobs/routes.ts:11,40, replit_dev cf5241ad6]; (3) unplanned: no role check [code: server/modules/work-orders/routes.ts:103, replit_dev cf5241ad6]. Normal sign-in and vessel access apply to all.
Prerequisites (switches, settings, job/component state): Office 'Generate Now' and office per-job 'Generate WO' both need the vessel's 'office work-order generation' switch ON (off by default, set by a Sail Admin on 'Lead Time & Grace Period Settings') [code: workOrderGenerationGate.ts:71-87,150-161; jobService.ts:576-583, replit_dev cf5241ad6]. Unplanned needs no switch. A job with an active work order cannot get another one [manual: Office PMS Technical manual, June rev, p.18].
Steps:
1. Planned (scheduled) work orders — generated by the system from each job's frequency and next due date. ON THE SHIP: automatic, once a day, no user action [code: server/services/jobDueScanner.ts:163-195; server/routes.ts:166-178, replit_dev cf5241ad6]. IN THE OFFICE: nothing runs automatically; a Sail Admin can click 'Generate Now' on the Work Orders screen for one vessel, only if that vessel's switch is on [code: workOrderController.ts:131-148, replit_dev cf5241ad6]. Details: planned-wo-ship-daily-scan.md and office-generate-now.md.
2. One job on demand — Components → (Office: select the vessel) → open the component → Part C → 'Generate WO' → choose the reason (Planning / Breakdown / Other) [manual: Office PMS Technical manual, June rev, p.18]. No role check on this path (sign-in and vessel access still apply); in the office only if the vessel switch is on; the job must be active and must not already have an active work order. Details: office-generate-wo-per-job.md.
3. Unplanned work — Work Orders → (Office: select the vessel) → '+ Unplanned W.O' → Part A, Save → Part B, Submit Work Order [manual: Office PMS Technical manual, June rev, p.29]. No role check on this path, no switch. Details: unplanned-wo.md.
Exceptions / edge cases: The Sail Admin requirement belongs to 'Generate Now' only; it does not apply to per-job 'Generate WO' or to unplanned work orders. [code: workOrderController.ts:133 is the only caller of the Sail Admin gate, replit_dev cf5241ad6]
Where the manual differs: The June manuals describe only ways 2 and 3 and state no office conditions; automatic ship generation and 'Generate Now' are absent from them. See CONFLICTS.md.
