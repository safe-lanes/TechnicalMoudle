# MOC USER MANUAL

* To add any additional **Implication**, click on the **"+Add Implication"** icon.

* Proceed to **Section C3 – Risk Assessment**, where you can either upload an existing RA file using the **Upload** icon or link/create a new RA using the **Link** icon.

* After clicking the Link icon, it will re-direct you to the Vessel Risk Assesment page. (See Figure 9)

☞ **Note:** Any additional implication can be deleted using the **Delete** icon.
All actions linked to that implication will also be deleted.
After deletion, review the **Part E – Action table** to ensure data consistency.

☞ **Note:** After selecting the relevant **RA option**, the user will be redirected to the **VRA form**.
Once the details are saved, the RA will be stored in the appropriate **RA sub-module**.
Click the **Back** icon on the RA form to return to the MoC form.
