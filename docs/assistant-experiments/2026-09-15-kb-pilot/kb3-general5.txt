
== How do I record a stock transaction for spares? · A-kb-base · gate=answer · top cites=[('Technical - PMS User Manual_Vess', ' INVENTORY TRANSACTIONS (p.38)'), ('Technical - PMS User Manual_Vess', 'CTION OF SPARES IN BULK (p.40)')]
To record a stock transaction for spares, follow these steps:

1. Click the 'Spares' sub-submodule to access the inventory.
2. Click the 'Location' icon in the table column to view and update stock availability based on the storage location.
3. Choose the required location (Location A or Location B), then click + Create New Location to create a new inventory location if needed.
4. Click the ‘Save’ button to save and update the field.

Source: Technical - PMS User Manual_Vessel Specific_R3_08.07.2026 — 1.1.7.2 HOW TO UPDATE & TRACK SPARE INVENTORY TRANSACTIONS (p.38)

== How do I add a component to a vessel? · A-kb-base · gate=answer · top cites=[('Technical - PMS User Manual For ', '3 HOW TO ADD COMPONENTS (p.24)'), ('Technical - PMS User Manual For ', ' HOW TO EDIT COMPONENTS (p.25)')]
To add a component to a vessel, follow these steps:

1. Select the required vessel from the 'Vessel' dropdown.
2. Click on the 'Add Component' button.
3. Enter the required details for the component.
4. Click the 'Save' button to save the component information.
5. Click the 'Submit' button to add the component to the components panel.

Note: All mandatory fields must be completed before the record can be saved or submitted.

Source: Technical - PMS User Manual For Office_Sail Admin_R2_08.06.2026 — 1.1.4.3 HOW TO ADD COMPONENTS (p.24)
